# 고장 유형과 시그니처

이 문서는 앱이 **어떤 고장을 어떤 근거로 구분하는지**, 그리고 **그 구분에 무엇이 필요한지**를 정리합니다.

핵심 원칙 하나가 문서 전체를 관통합니다:

> **설비 설정이 분석 방향을 정합니다.** 베어링 품번을 모르면 결함주파수를 대조할 수 없고, 마운팅을 모르면 어느 고주파까지 믿을 수 있는지 알 수 없습니다. 앱은 그럴 때 점수를 0으로 주는 대신 **"측정 불가"** 로 표시합니다 — 볼 수 없는 것과 가능성이 낮은 것은 다르기 때문입니다.

## 학습은 분석의 전제가 아닙니다

판정 축은 넷인데 성격이 둘로 갈립니다.

| | 축 | 학습 | 어디에 필요한가 |
| :--- | :--- | :--- | :--- |
| **필수** | ISO 존 · 결함 패턴 | **불필요** | 상세분석·리포트가 이 둘만으로 완결됩니다 |
| **보강** | 베이스라인 · 대역 | 필요 | "평소 대비"는 지속 감시의 개념입니다 |

일회성 분석에는 "평소"가 없습니다. 그래서 학습이 안 된 설비에서도 상세분석과 리포트는 그대로 나오고, 학습된 축이 있으면 **민감도가 더해질 뿐**입니다.

## 두 갈래로 나눠 봅니다

| | 묻는 것 | 계열 | 조치 |
| :--- | :--- | :--- | :--- |
| **진동 축** | 이 지점 진동이 커졌나 | 서브동기 · 1× 대역 · 결함 대역 · 고주파 · vh1~vh4 | 밸런싱 · 정렬 · 체결 (시간 단위) |
| **베어링 축** | 이 베어링이 상했나 | 포락선 BPFO · BPFI · BSF | 부품 조달 · 분해 (주 단위) |

**둘을 한 덩어리로 두면 안 됩니다.** 실측에서 정상 베어링이 `2~4 kHz 대역 ×3.97`로 결함 베어링(`×2.35`)보다 높게 나왔습니다 — 옆 베어링의 결함이 축을 타고 그 센서에도 실렸기 때문입니다. "진동이 크다"는 맞지만 "그 베어링이 상했다"는 아닙니다. 포락선 결함주파수만 보면 정상 최대 `×1.26` / 결함 최소 `×1.42`로 갈립니다.

## 회전체 계통 — 진동 축

### 불평형 (Imbalance)
회전체 질량이 편심된 상태입니다.

- **시그니처** — 1× 동기 성분이 지배. 하모닉이 적음
- **확정 조건** — **위상과 축방향 측정이 있어야** 정렬불량과 구분됩니다. 단일 채널로는 원리적으로 판별 불가라 앱이 "측정 불가"로 표시합니다
- **조치** — 현장 동적 밸런싱

### 정렬 불량 (Misalignment)
커플링으로 이어진 두 축의 중심이 어긋난 상태입니다.

- **시그니처** — 2× 성분이 우세. 축방향 진동 동반
- **확정 조건** — 불평형과 같습니다(위상·축방향 필요)
- **조치** — 레이저 얼라인먼트

### 기계적 풀림 (Looseness)
체결·고정·하우징이 헐거운 상태입니다.

- **시그니처** — **1×의 정수배 하모닉이 여러 개**(3개 이상). 지배 성분이 동기
- **조치** — 체결·고정·베어링 하우징 점검

## 베어링 계통 — 베어링 축

결함 주파수는 회전수와 베어링 기하로 정해집니다. **품번(또는 형상)을 넣어야** 대조가 가능합니다.

| 신호 | 어디가 상했나 | 계산식 (× 회전수) |
| :--- | :--- | :--- |
| **BPFO** | 바깥 궤도(외륜) | (n/2)(1 − (d/D)cos α) |
| **BPFI** | 안쪽 궤도(내륜) | (n/2)(1 + (d/D)cos α) |
| **BSF** | 구름체(볼·롤러) | (D/2d)(1 − ((d/D)cos α)²) |
| FTF | 케이지 | (1/2)(1 − (d/D)cos α) |

### 왜 포락선이 필요한가
결함을 지날 때마다 나는 충격은 하우징의 **수 kHz 공진을 울립니다.** 원시 스펙트럼에는 "고주파가 있다"까지만 보이고 **"몇 Hz로 두들기나"** 는 진폭 변조에 숨습니다. 포락선 복조가 그 반복 주파수를 선으로 꺼냅니다.

### 복조 대역은 1~5 kHz 고정입니다
자동 선택(커토그램)을 쓰지 않습니다. 두 번 시도했고 두 번 다 졌습니다.

**① 안티에일리어싱 잡음에 붙잡힙니다.** Nyquist 바로 아래는 필터가 신호를 죽인 구간이라 남은 수치 잡음의 첨도가 폭발하고, 커토그램이 늘 그쪽으로 끌려갑니다. 실측에서 상한이 없으면 결함 종류 적중이 **0/18**, Nyquist의 80%로 자르니 **7/18**이었습니다.

**② 상한을 걸어도 전기 성분에 붙잡힙니다.** 아래에 자세히 적습니다.

첨도를 해석 신호에 거는 **정식 스펙트럼 첨도(SK)로 고쳐도 결과는 같았습니다** — real 6% · 복소 절대값 6% · 복소 SK 7%로, 셋 다 12~16 kHz대를 고릅니다. 구현 결함이 아니라 **목적함수 자체의 문제**입니다. 첨도는 구조적으로 톤성 대역을 깎기 때문에(순수 정현파의 첨도 1.5 < 가우시안 3), 결함이 뚜렷할수록 오히려 그 대역을 피합니다.

### 커토그램이 전기 성분에 붙잡히기도 합니다

Nyquist 상한만으로는 부족합니다. 인버터 구동 시험대(Paderborn)에서는 커토그램이
**정상·결함 가릴 것 없이 12~19 kHz를 골랐고**, 그 대역의 포락선이 한 성분에 덮여 있었습니다.

같은 베어링을 회전수만 바꿔 재보면 정체가 갈립니다:

| 축 회전수 | 지배 차수 | 절대 주파수 |
| :--- | :--- | :--- |
| 1500 rpm | 2.10× | **52.5 Hz** |
| 900 rpm | 3.50× | **52.8 Hz** |

**차수는 바뀌고 절대 주파수는 그대로**입니다. 베어링 결함주파수는 회전수에 비례하므로
이것은 기계가 아니라 전기·구조 기원입니다. 그 결과 결함 검출이 **1/104**(900 rpm에서는 **0/84**)까지 떨어졌습니다.

그래서 **복조 대역을 1~5 kHz로 고정**했습니다. 383 케이스 전체에서 결함 검출이
**10% → 25%**로 오르고, 정상 오탐은 2% → 3%, 종류 적중은 오히려 90% → 95%가 됐습니다.
커토그램은 계속 계산해 화면에 띄웁니다 — 어느 대역이 충격적인지는 그 자체로 진단 정보이기 때문입니다.
다만 **판정에는 쓰지 않습니다.**

> **대형 설비에서 이 대역이 맞는지는 모릅니다.** 검증 풀에 대형 설비가 없습니다.
> 1~5 kHz에 실제로 자주 걸리는 것은 **가속도계 마운팅 공진**(부착 방식에 따라 수 kHz)이고,
> 베어링 링 자체의 굴곡 모드는 설비가 커질수록 **낮아집니다.** 그래서 "대형 설비는 공진이
> 더 높아서 놓친다"는 설명은 물리적으로 맞지 않습니다 — **어느 방향으로 틀리는지 측정된 바가 없습니다.**

샘플링이 낮아 1~5 kHz가 성립하지 않으면(Nyquist가 5 kHz에 못 닿으면) **전대역 해석 신호로 복조합니다.** 옛 버전은 이때 커토그램으로 되돌아갔는데 위 이유로 없앴습니다. 정류(절대값)로 물러서지 않는 것도 같은 이유입니다 — 그 태그만 다른 방법으로 재면 판정 경로가 둘로 갈립니다.

> **아슬아슬했던 부분** — 이 붙박이 성분(52.5 Hz, 2.10×)은 BSF(50.9 Hz, 2.04×)와 **3% 차이**입니다.
> BSF 허용오차가 ±1%가 아니라 ±2%였다면 **정상 베어링이 전부 볼 결함으로 오탐**났을 것입니다.
> 4극 1500 rpm 인버터 구동은 아주 흔한 구성입니다.

### FTF는 결함 근거가 아닙니다
**케이지는 정상 베어링에서도 항상 돕니다.** 실측에서 정상 채널이 첫날부터 `0.45× 하모닉 3개`를 계속 냈습니다. 관측 사실로만 기록하고 점수에는 넣지 않습니다.

### 오일 훨 (Oil whirl)
유막(저널) 베어링에서 축이 유막 위를 떠도는 현상입니다.

- **시그니처** — 0.38~0.48× 비동기 성분 지배
- **중요** — **구름베어링으로 형식이 지정되면 후보에서 내립니다.** 유막 베어링에서만 생기는 현상이라 물리적으로 성립하지 않습니다. 형식 미지정이면 알 수 없으므로 그대로 둡니다

### 케이지 결함 (FTF 추정)
- **시그니처** — 0.35~0.45× 지배. 품번을 몰라도 이 구간 판정은 가능합니다(구름베어링의 d/D가 대부분 0.15~0.25라 FTF가 그 범위에 갇힘)
- **주의** — 위 "FTF는 결함 근거가 아니다"와 별개 항목입니다. 이쪽은 **원시 스펙트럼의 지배 차수**를 보고, 저쪽은 포락선 결함주파수 대조입니다

## 구동·부하 계통

### 벨트·풀리 (Belt)
- **시그니처** — 벨트 통과주파수와 그 하모닉
- **필요 설정** — **풀리경 2개 + 벨트 길이.** 없으면 대조 자체가 불가합니다
- 풀리비만 알면 종동축 1×는 대조되어, 정체 모를 비동기 성분의 **귀속**이 닫힙니다

### 베인/블레이드 통과 (Vane pass)
- **시그니처** — 날개수 × 1×
- **필요 설정** — 임펠러 날개수

### 기어 메시 (Gear mesh)
- **시그니처** — 잇수 × 1×(메시 주파수)와 **1× 간격 측대역**
- **음성 소견이 유의미한 드문 경우** — 메시는 관측되는데 측대역이 없으면 그게 **정상 기어의 모습**입니다

### 독립 회전원 (종동축·인접 기계)
- **시그니처** — **비동기** 기본파 + 그 자체 하모닉 3개 이상
- 벨트 종동축·인접 기계·기어 종동축이 대개 정체입니다. 구동 계통도 한 장이면 귀속이 닫힙니다

### 전기적 (Electrical)
- **시그니처** — 라인 주파수 관련 성분
- **확정** — 전원 차단 시 소멸하는지 확인해야 합니다(정지 시험)

## 설정이 무엇을 여는가

| 설정 | 없으면 못 하는 것 |
| :--- | :--- |
| **회전수(RPM)** | 차수 해석 전부 — 모든 후보가 닫힘 |
| **단위** | ISO 존 판정(속도 규격이라 가속도·변위는 변환 필요) |
| **머신 클래스** | ISO 존 경계 |
| **베어링 품번·형상** | BPFO/BPFI/BSF 대조 · 오일훨 배제 |
| **마운팅** | 고주파 유효 상한 — 그 위 대역은 마운팅 공진일 수 있음 |
| **풀리경·벨트길이** | 벨트 통과주파수 |
| **날개수 / 기어 구동** | 베인 통과 / 메시 주파수 |

## 지금 어디까지 되는가

공개 데이터셋 4종(CWRU · MFPT · Paderborn · XJTU-SY) **383 케이스** 실측입니다.

| | 결과 |
| :--- | :--- |
| **정상 오탐** | **3/100 (3%)** |
| **결함 검출** | **188/283 (66%)** |
| 검출된 것 중 부위 적중 | 157/174 |


마지막 줄이 중요합니다. "검출된 것 중 83%"는 채택이 보수적일수록 좋아지는 조건부 값이라
단독으로 인용하면 안 됩니다. 실제로 손에 남는 것은 **결함 셋 중 하나에서 부위까지 맞히는 정도**입니다.

### 부위별 — 외륜만 잘 됩니다

| | 결함이 하중대에 | 신호 | 성적 |
| :--- | :--- | :--- | :--- |
| **외륜** | **고정** | 충격 크기가 일정 → 피크가 선다 | 가장 좋음 |
| 내륜 | 축과 함께 드나듦 | `BPFI ± k·1×` 측대역으로 분산 | 중간 |
| 구름체 | 케이지와 함께 드나듦 | `BSF ± k·FTF` 측대역으로 분산 | **부위 단정 불가** |

구름체는 검출은 되지만 **부위를 단정하지 않습니다.** 실측에서 구름체 라벨 적중이 0이었고
반대로 내륜·외륜 7건이 구름체로 잘못 갔습니다. 물리적으로도 결함 구름체는 레이스를
함께 상하게 하므로 "부위 미상"이 정직합니다.

### 시간축에서 보면 — 외륜은 미리, 내륜은 늦게

전 수명 시험(XJTU-SY, 1분 간격)으로 **"고장까지 얼마나 남기고 첫 경보를 냈나"** 를 쟀습니다.

| 베어링 | 부위 | 첫 경보 시점 |
| :--- | :--- | :--- |
| 3_5 · 2_2 · 1_1 | 외륜 | 수명의 **97% · 67% · 41%** 남기고 |
| 2_1 · 3_3 | 내륜 | 수명의 **8%** 남기고 |
| 1_4 | 케이지 | **미검출** |

스냅샷 검출률보다 이 표가 실제 쓸모를 더 정직하게 보여줍니다 —
**외륜은 정비 계획을 세울 시간을 주지만, 내륜은 "곧 선다"는 통보에 가깝습니다.**

### 오경보는 얼마나 우는가

건전 구간에서 알람 상태기(진입 확인 2회 · 복귀 5회)를 적용하면 **자산당 월 12.5건**입니다.
다만 그 2건 모두 "초기 열화였을 수도 있는" 케이스이고, 6개 베어링 중 **4개는 완전히 조용했습니다.**
가속수명 시험이라 "앞 절반은 건전"이라는 가정 자체가 흔들려, 이 값은 **보수적 상한**으로 읽어야 합니다.

### 종류를 단정하지 않는 경우
1·2순위 배수가 근접하면 **후보를 나열하고 "구분 불충분"** 이라고 적습니다. 실측에서 `BPFO ×1.42 / BSF ×1.39`(2% 차)를 "외륜"으로 단정하고 있었습니다.

**어느 쪽이든 베어링 교체이므로 정비 계획은 탐지만으로 섭니다.** 종류가 필요한 것은 **근본원인 분석**입니다 — 내륜은 과부하·정렬불량, 외륜은 하우징·전류 통과를 의심하는 식으로 재발 방지가 갈립니다.
