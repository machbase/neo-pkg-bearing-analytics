# 故障タイプとシグネチャ

[English](./faults.en.md) | [한국어](./faults.kr.md) | [日本語](./faults.ja.md)

本書では、アプリが**どの故障をどのような根拠で見分けるのか**、そして**その見分けに何が必要なのか**を整理します。

文書全体を貫く核心原則が一つあります。

> **設備設定が分析の方向を決めます**。ベアリングの型番が分からなければ欠陥周波数を照合できず、マウンティングが分からなければどの高周波まで信頼できるのか分かりません。そのような場合、アプリはスコアを0にする代わりに「**測定不可**」と表示します。見えないことと、可能性が低いことは別物だからです。

## 学習は分析の前提ではありません

判定軸は4つありますが、役割は2つに分かれます。

| | 軸 | 学習 | 役割 |
| :--- | :--- | :--- | :--- |
| **等級を決める軸** | 欠陥パターン・ISOゾーン | **不要** | 等級と通知。詳細分析・レポートもこの2つだけで完結します |
| **根拠軸** | ベースライン・帯域 | 必要 | 「平常比」の根拠を表示します。等級や通知は作りません |

単発の分析には「平常時」がありません。そのため、学習していない設備でも詳細分析とレポートはそのまま出力され、学習済みの軸があれば**根拠がもう一層見えるだけ**で、等級は変わりません。

## 2つに分けて見ます

| | 問うこと | 系列 | 対処 |
| :--- | :--- | :--- | :--- |
| **振動評価軸** | この測定点の振動が大きくなったか | サブシンクロナス · 1×帯域 · 欠陥帯域 · 高周波 · 1\~2 · 2\~4 · 4\~8 · 8 kHz+ | バランシング・芯出し・締結（時間単位） |
| **ベアリング評価軸** | このベアリングが損傷したか | 包絡線 周期性 · BPFO · BPFI · BSF | 部品調達・分解（週単位） |

**2つを一まとめにしてはいけません**。隣のベアリングの欠陥が軸を伝わってくると、健全なベアリングに取り付けたセンサーの高周波帯域のほうが、欠陥のあるベアリングよりも高く出ることがあります。「振動が大きい」は正しくても、「そのベアリングが損傷した」は正しくありません。包絡線の欠陥周波数だけを見れば、両者を区別できます。

## 回転体系統 — 振動評価軸

### アンバランス（Imbalance）
回転体の質量が偏心した状態です。

- **シグネチャ** — 1×の回転同期成分が支配的。高調波は少ない
- **確定条件** — **位相と軸方向の測定があって初めて**ミスアライメントと区別できます。単一チャンネルでは原理的に判別できないため、アプリは「測定不可」と表示します
- **対処** — 現地での動バランス調整

### ミスアライメント（Misalignment）
カップリングでつながった2つの軸の中心がずれた状態です。

- **シグネチャ** — 2×成分が優勢。軸方向振動を伴う
- **確定条件** — アンバランスと同じです（位相・軸方向の測定が必要）
- **対処** — レーザーアライメント

### 機械的ゆるみ（Looseness）
締結・固定・ハウジングがゆるんだ状態です。

- **シグネチャ** — **1×の整数倍の高調波が複数**（3つ以上）。支配成分は回転同期
- **対処** — 締結・固定・ベアリングハウジングの点検

## ベアリング系統 — ベアリング評価軸

欠陥周波数は回転数とベアリングの幾何形状で決まります。**型番（または形状）を入力して初めて**照合が可能になります。

| 信号 | 損傷箇所 | 計算式（× 回転数） |
| :--- | :--- | :--- |
| **BPFO** | 外側の軌道（外輪） | (n/2)(1 − (d/D)cos α) |
| **BPFI** | 内側の軌道（内輪） | (n/2)(1 + (d/D)cos α) |
| **BSF** | 転動体（玉・ころ） | (D/2d)(1 − ((d/D)cos α)²) |
| FTF | 保持器 | (1/2)(1 − (d/D)cos α) |

### なぜ包絡線が必要か
欠陥を通過するたびに生じる衝撃は、ハウジングの**数kHzの共振を鳴らします**。生スペクトルでは「高周波成分がある」ところまでしか見えず、「**何Hzで叩いているか**」は振幅変調の中に隠れています。包絡線（エンベロープ）復調が、その繰り返し周波数を線スペクトルとして取り出します。

### 復調帯域は1\~5 kHzに固定しています
衝撃が最も際立つ帯域を自動で選ぶ方式（カートグラム）は判定に使いません。この方式は欠陥ではない信号 — 高周波端のフィルター雑音、インバーターが作る電気的成分 — に引っ張られやすく、欠陥が明瞭なほどかえってその帯域を避ける性質があるため、公開データでの検証で検出率が大きく低下しました。

そこで、等級を決める欠陥パターンと詳細分析の包絡線は、**復調帯域を1\~5 kHzに固定**しました。（帯域抽出が蓄積する包絡線の推移は、マウンティング上限・サンプリング限界より下の最も高いオクターブを使います。）カートグラムは引き続き計算し、詳細分析の**帯域別衝撃性**チャートに表示します。どの帯域が衝撃的かは、それ自体が診断情報だからです。ただし、**判定には使いません**。

サンプリング周波数が低く1\~5 kHzが成立しない場合（5 kHzが測定可能な最大周波数の95%以内に収まらない場合 — サンプルレート約10.5 kHz未満）は、**全帯域で復調します**。このときは根拠が弱く、初期のベアリング欠陥は捉えられません。

> **大型設備でこの帯域が適切かどうかは分かっていません**。検証データに大型設備が含まれていないためです。
> 1\~5 kHzで実際によく現れるのは**加速度計のマウンティング共振**（取り付け方法によって数kHz）であり、
> ベアリングの軌道輪そのものの曲げモードは、設備が大きくなるほど**低くなります**。そのため、「大型設備は共振が
> より高いので見逃す」という説明は物理的に正しくありません — **どちらの方向に外れるのかは測定されていません**。

### FTFは欠陥の根拠ではありません
**保持器は正常なベアリングでも常に回っています**。健全なチャンネルでも保持器の回転成分が最初からずっと見えるため、観測事実としてのみ記録し、スコアには含めません。

### オイルホワール（Oil whirl）
すべり軸受（ジャーナル軸受）で、軸が油膜の上で振れ回る現象です。

- **シグネチャ** — 0.38\~0.48×の非同期成分が支配的
- **重要** — **形式が転がり軸受に指定されると、候補から外します**。油膜を持つすべり軸受でしか起きない現象なので、物理的に成立しないためです。形式が未指定の場合は判断できないため、候補に残します

### 保持器欠陥（FTF推定）
- **シグネチャ** — 0.35\~0.45×が支配的。型番が分からなくてもこの範囲の判定は可能です（転がり軸受のd/Dはほとんどが0.15\~0.25なので、FTFがその範囲に収まるため）
- **注意** — 上記の「FTFは欠陥の根拠ではない」とは別の項目です。こちらは**生スペクトルの支配次数**を見るもので、あちらは包絡線での欠陥周波数の照合です

## 駆動・負荷系統

### ベルト・プーリ（Belt）
- **シグネチャ** — ベルト通過周波数とその高調波
- **必要な設定** — 駆動方式 **ベルト**、プーリの**ピッチ径**2つ（D1 駆動側・D2 従動側）+ ベルト長。ベルト長がないと、ベルト通過周波数は照合できません
- プーリ比が分かるだけでも反対側の軸の1×が照合でき、正体不明の非同期成分の**帰属**が確定します
- **センサーがベルトの反対側（ファン・ポンプなど）に付いている場合は**、センサー位置を**従動側**に設定してください。すると欠陥パターン・欠陥周波数・帯域が**従動軸の回転数**で計算されます。測定した従動軸回転数を入力すればその値を、空欄にすれば RPM × D1 ÷ D2 を使います。従動側なのに回転数が分からない場合、そのタグは欠陥パターンを測定しません。モーター回転数で照合すると、無関係な周波数が偶然一致してしまうためです

> 従動軸回転数が1\~2%ずれるだけで、欠陥は捉えても部位をよく取り違えます。プーリの外径ではなくピッチ径を使うか、測定した回転数を入力してください。

### ベーン／ブレード通過（Vane pass）
- **シグネチャ** — 羽根数 × 1×
- **必要な設定** — インペラの羽根数

### 歯車かみ合い（Gear mesh）
- **シグネチャ** — 歯数 × 1×（かみ合い周波数）と**1×間隔の側帯波**
- **陰性所見に意味があるまれなケース** — かみ合い成分は観測されるのに側帯波がなければ、それが**正常な歯車の姿**です

### 独立回転源（従動軸・隣接機械）
- **シグネチャ** — **非同期**の基本波 + それ自身の高調波3つ以上
- ベルトの従動軸・隣接機械・歯車の従動軸であることがほとんどです。駆動系統図が1枚あれば帰属が確定します

### 電気的要因（Electrical）
- **シグネチャ** — 電源周波数に関連する成分（60 Hz系統なら120 Hz）。回転数が変わっても動かない
- **確定** — 電源遮断時に消えるかどうかを確認する必要があります（停止試験）

## 設定が何を可能にするか

| 設定 | ない場合 |
| :--- | :--- |
| **回転数（RPM）** | 次数解析のすべて — すべての候補が閉じ、欠陥パターン（等級）と帯域抽出も止まります |
| **ベアリングの型番・形状** | 欠陥パターン（等級）・BPFO/BPFI/BSFの照合・オイルホワールの除外 |
| **単位** | 空欄なら速度（mm/s）とみなします — 加速度・変位センサーはISO換算がずれ、等級の高さが誤ります |
| **Class** | 空欄ならClass IIのゾーン境界で判定します |
| **マウンティング** | 高周波の有効上限 — それより上の帯域はマウンティング共振の可能性があるのに、区別して表示できません |
| **プーリのピッチ径・ベルト長** | ベルト通過周波数・従動軸の1× |
| **センサー位置（ベルト）・従動軸回転数** | 従動側センサーの欠陥周波数がモーター回転数で計算され、ずれます |
| **羽根数／歯車駆動** | ベーン通過周波数／かみ合い周波数 |

## 現時点でどこまでできるか

公開データセット4種（CWRU · MFPT · Paderborn · XJTU-SY）の383件で検証した結果をまとめると、次のとおりです。

| | 結果 |
| :--- | :--- |
| 正常の誤検知 | 100件中3件 (3%) |
| 欠陥の検出 | 283件中183件 (65%) |
| 欠陥全体のうち部位まで的中 | 283件中153件 (約54%) |

検出したものだけで見ると部位の的中率ははるかに高く見えますが、その値は判定を保守的にするほど良くなる条件付きの値なので、単独で見てはいけません。手元に残るのは**欠陥の2件に1件強で部位まで当てる程度**です。詳しい表は[このツールが行うことと行わないこと](./scope.ja.md)にあります。

### 部位別 — うまくいくのは外輪だけです

| | 欠陥が負荷域に | 信号 | 成績 |
| :--- | :--- | :--- | :--- |
| **外輪** | **固定** | 衝撃の大きさが一定 → ピークが立つ | 最も良い |
| 内輪 | 軸とともに出入りする | `BPFI ± k·1×` の側帯波に分散 | 中程度 |
| 転動体 | 保持器とともに出入りする | `BSF ± k·FTF` の側帯波に分散 | **部位を断定できない** |

転動体は検出はされますが、**部位を断定しません**。検証では転動体と名付けた判定がほとんど当たらず、逆に内輪・外輪の欠陥が転動体と誤って判定されることもありました。物理的にも、欠陥のある転動体は軌道輪も一緒に傷めるため、「部位不明」とするのが誠実です。

### 時間軸で見ると — 外輪は早めに、内輪は遅れて

全寿命試験のデータで「故障のどれだけ前に最初の警報を出したか」を測ると、**外輪は保全計画を立てる時間をくれますが、内輪は「もうすぐ止まる」という通告に近い**ものです。数値は[このツールが行うことと行わないこと › 時間軸での成績](./scope.ja.md#時間軸での成績--全寿命試験)にあります。

### 種類を断定しない場合
帯域抽出が蓄積する包絡線の欠陥周波数系列（BPFO・BPFI・BSF）が一緒に上がり、1位と2位が近い場合は、**候補を列挙して「区別不十分」と記載します**。等級を決める欠陥パターンは、最も強い候補を1つ選びます。

**どちらであってもベアリング交換になるため、保全計画は検出だけで立てられます**。種類が必要になるのは**根本原因分析**です — 内輪なら過負荷・ミスアライメント、外輪ならハウジング・電流通過を疑う、というように再発防止策が分かれます。
