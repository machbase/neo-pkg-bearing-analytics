# 사용 방법

**한국어** | [English](./usage.en.md)

설정을 마치면 세 개의 주 탭 — 모니터링 · 상세분석 · 리포트 생성 — 으로 작업합니다.

## 모니터링

전체 설비 상태를 한눈에 보는 화면입니다.

### 요약 바

상단 요약 바에는 전체 설비 수와 심각도별(양호 · 주의 · 위험 · 심각) 개수, 최근 이벤트가 표시됩니다. 심각도 칸을 누르면 그 등급의 설비만 카드 그리드에 걸러 보여 주고, 다시 누르면 필터가 풀립니다.

### 설비 카드

선택한 태그마다 카드가 하나씩 생깁니다. 각 카드에는 별칭, 최근 RMS 값과 스파크라인, 심각도 등급 배지가 표시됩니다. 카드를 누르면 그 태그의 **상세분석**으로 이동합니다.

### 이벤트 목록

아래쪽 이벤트 목록에는 최근에 기록된 이벤트가 시각 · 태그 · 유형 · 지표 · 등급으로 표시됩니다. 각 행을 누르면 그 이벤트가 발생한 시점의 상세분석으로 이동합니다.

### 이벤트 내보내기

이벤트 목록의 **저장** 버튼을 누르면 기간과 파일 형식(CSV · JSON)을 고르는 팝업이 뜹니다. 지정한 기간의 이벤트를 파일로 내려받을 수 있습니다.

## 알람과 이벤트

헤더의 알람 표시를 누르면 알람을 켜고 끌 수 있습니다. 이 상태는 저장되어, 앱을 다시 열어도 유지됩니다.

알람이 켜져 있는 동안 앱은 열려 있는 내내 선택된 태그를 주기적으로 판정합니다.

- **임계 판정은 항상** — 등급이 바뀌면(양호→주의 등) 이벤트를 기록합니다.
- **베이스라인 판정은 학습 시** — 정상 상태를 학습한 태그는 베이스라인 이탈도 함께 기록합니다.

판정 결과는 Neo의 LOG table(`NEO_VIBE_EVENTS`)에 이벤트로 쌓입니다.

- **양호(정상)는 이벤트로 기록하지 않습니다** — 주의 이상만 남습니다.
- **이벤트는 자동 삭제되지 않습니다** — 이력도 데이터이므로 보존됩니다. 필요하면 이벤트 내보내기로 보관합니다.

> 알람은 앱이 열려 있는 동안만 동작합니다. 상시 백그라운드 감시가 아니라, 화면을 열어 둔 동안의 경량 감시입니다.

## 상세분석

한 태그를 깊이 들여다보는 화면입니다. 모니터링 카드나 이벤트 행에서 들어옵니다.

상세분석은 **스냅샷**입니다 — 들어온 시점의 데이터로 고정되며, 화면이 실시간으로 계속 바뀌지 않습니다. 최신 상태를 다시 보려면 다시 들어오거나 태그를 바꿉니다.

### 태그·기간 선택

- 화면 상단의 드롭다운으로 분석할 태그를 바꿀 수 있습니다.
- 조회 기간은 프리셋으로 고릅니다 — 1시간 · 6시간 · 24시간 · 전체 · 직접 입력. 기본은 1시간입니다.
- 그 태그의 데이터가 프리셋 길이보다 짧으면 해당 프리셋은 비활성화됩니다. 누르면 "데이터가 부족합니다" 안내가 뜨며, 이때는 **전체**로 확인합니다.
- **직접 입력**은 시작·종료 일시를 분 단위까지 지정합니다.

차트의 시간축은 선택한 기간 전체를 채웁니다. 데이터가 없는 구간은 빈 곳으로 남아, 실제로 어디에 데이터가 있는지 그대로 보입니다.

### 차트

| 차트 | 보는 것 |
| :--- | :--- |
| 원시 파형 | 시간 영역 진동 파형 |
| RMS · Peak-to-Peak · Crest Factor · 첨도 추이 | 시간에 따른 대표 지표 변화 |
| 결함 대역 에너지 · 대역 첨도 추이 | 베어링 결함 대역의 에너지와 충격성 변화 |
| FFT 스펙트럼 | 주파수 성분. 베어링 등록 시 1×/2×/3×, BPFO/BPFI/BSF/FTF 마커 표시 |
| 포락선 (Envelope) | 충격성 결함이 만드는 변조 성분 |
| 켑스트럼 · 스펙트로그램 | 주기 성분과 시간-주파수 변화 |

### 진단과 권고 조치

차트 아래에는 규칙 기반 진단이 표시됩니다. 불균형 · 정렬 불량 · 베어링 내륜/외륜 · 풀림 · 기어 등의 결함을 판정하고, 판정 근거와 우선순위가 매겨진 권고 조치를 함께 제시합니다.

### LLM 소견 (선택)

LLM을 연동했다면, 상세분석의 모든 차트 실측값을 근거로 서술형 전문가 소견을 생성할 수 있습니다. 프로바이더는 화면의 드롭다운에서 고릅니다. 연동하지 않았으면 규칙 기반 진단만으로도 충분히 동작합니다.

## 리포트 생성

분석 결과를 문서로 남기는 화면입니다.

1. 리포트에 담을 대상 태그를 고릅니다. (기본은 미선택)
2. **리포트 생성**을 누르면 진동 분석 리포트가 만들어져 `vibration-reports/`에 저장됩니다.
3. 보관함에서 저장된 리포트를 미리보기하거나 삭제할 수 있습니다.

LLM을 연동하면 리포트에 소제목이 있는 서술형 종합 소견이 함께 들어갑니다. 연동하지 않아도 지표·차트 기반 리포트는 정상 생성됩니다.

## 사용 팁

- 처음에는 태그 한두 개만 선택해 동작을 확인한 뒤 대상을 넓힙니다.
- 진단 정확도를 높이려면 **설비 정보**에 RPM과 베어링 모델을 등록합니다.
- "평소와 다른" 변화까지 잡으려면 정상일 때 **정상 상태 학습**을 해 둡니다.
- 이벤트가 쌓이면 주기적으로 **저장**으로 내보내 별도 보관합니다.
