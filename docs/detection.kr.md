# 이상 판정 원리

**한국어** | [English](./detection.en.md)

이 문서는 앱이 **무엇을 재고, 어떤 기준으로 등급을 매기고, 언제 이벤트를 남기는지**를 설명합니다.

설정 화면의 각 항목과 알림 받는 법은 [알람과 이벤트](./alarms.kr.md)에 있습니다. 이 문서는 그 설정이 실제로 무엇을 바꾸는지 이해하려는 분을 위한 것입니다.

## 전체 흐름

```
     원시 진동 데이터
            │
            ▼
    ① 판정값 만들기          구간 RMS 하나
            │
            ▼
    ② 세 기준으로 판정        ISO 존 · 베이스라인 · 대역 에너지
            │
            ▼
    ③ 등급 결정              셋 중 가장 나쁜 것
            │
            ▼
    ④ 상태 변화 확인          진입·복귀 확인 시간
            │
            ▼
        이벤트 기록 → 알림
```

이 과정은 설정한 **판정 주기**마다 태그별로 반복됩니다.

## ① 판정값 — 구간 RMS

판정에는 **한 구간 전체의 RMS 값 하나**를 씁니다. 가장 최근에 들어온 한 점이 아닙니다.

진동은 순간마다 출렁이므로 한 점으로 판정하면 등급이 계속 흔들립니다. 대신 "직전 10초 구간"처럼 일정 길이의 데이터를 하나의 실효값으로 합쳐서 봅니다.

여기서 **RMS 구간**과 **판정 주기**는 다른 설정입니다.

| 설정 | 뜻 | 예 |
| :--- | :--- | :--- |
| RMS 구간 | 얼마나 긴 데이터를 하나로 볼지 | 직전 10초 |
| 판정 주기 | 얼마나 자주 판정할지 | 10초마다 |

구간이 **길수록** 짧은 출렁임이 하나의 상태로 합쳐집니다 — 오경보가 줄지만 반응이 느려집니다. 구간이 판정 주기보다 짧으면 그 사이 데이터가 판정에 들어가지 않으므로 화면이 경고합니다.

부하가 주기적으로 변하는 설비라면 그 변동 주기보다 긴 구간을 잡는 것이 좋습니다. 짧으면 부하 변화 자체가 이상으로 잡힙니다.

## ② 세 가지 판정 기준

한 태그는 매번 세 가지 관점에서 동시에 판정됩니다. 각각 보는 것이 다릅니다.

| 기준 | 질문 | 학습 필요 |
| :--- | :--- | :---: |
| **ISO 존** | 국제 규격 기준으로 절대적으로 높은가? | 아니오 |
| **베이스라인** | 이 설비의 평소와 비교해 높은가? | 예 |
| **대역 에너지** | 특정 주파수 대역만 유독 높아졌는가? | 예 |

### ISO 존 — 절대 기준

ISO 10816 규격이 정한 진동 심각도 존(A 양호 → D 심각)에 대는 판정입니다. 설비 종류(머신 클래스)와 센서 단위에 따라 경계값이 달라집니다.

| 단위 | 양호↔주의 | 주의↔위험 | 위험↔심각 |
| :--- | ---: | ---: | ---: |
| mm/s · Class I (소형 ≤15kW) | 0.71 | 1.8 | 4.5 |
| mm/s · Class II (중형 15–75kW) | 1.12 | 2.8 | 7.1 |
| mm/s · Class III (대형·강성 기초) | 1.8 | 4.5 | 11.2 |
| mm/s · Class IV (대형·연성 기초) | 2.8 | 7.1 | 18.0 |
| g (가속도) | 0.5 | 1.0 | 2.0 |
| μm (변위) | 12 | 25 | 50 |

속도(mm/s) 값은 ISO 10816 기준값입니다. 가속도·변위는 규격이 정의한 물리량이 아니므로 **일반 참고값**이며, 설비에 맞게 조정해 쓰는 것을 전제로 합니다. 값은 판정 기준 화면에서 직접 바꿀 수 있습니다.

> **대역제한** — ISO 존 판정은 10–1000 Hz 구간만 남겨서 잽니다. 규격의 존 경계 자체가 그 대역에서 측정한 값으로 정해진 숫자이기 때문입니다. 고주파 성분이 많은 센서에서는 전대역 값과 ISO 값이 상당히 다를 수 있는데, 이 경우 존 판정에 쓰는 쪽이 규격에 맞는 값입니다.

### 베이스라인 — 평소 대비

설비가 정상일 때의 상태를 학습해 두고, 거기서 얼마나 벗어났는지 봅니다.

```
한계 = 평소 수준(μ) + k × 평소 변동폭(σ)
```

절대값이 아직 양호 존이어도 **평소보다 뚜렷하게 올라갔으면** 잡아냅니다. 설비마다 정상 수준이 다르므로, 규격 하나로는 놓치는 초기 변화를 여기서 잡습니다.

`k`는 민감도입니다. 작을수록 민감하고, 크면 확실할 때만 반응합니다.

평소 변동이 거의 없는 아주 안정된 설비에서는 한계가 평소 수준에 지나치게 붙을 수 있어, **최소한 평소의 +20%는 올라야** 이탈로 봅니다.

### 대역 에너지 — 주파수 대역별

전체 RMS로는 안 보이는 변화를 잡습니다. 베어링 결함이 자라도 전체 진동은 거의 안 움직이는데, 그 결함이 나타나는 주파수 대역만 보면 몇 배로 뜁니다.

대역은 회전주파수(1×)를 기준으로 다섯 구간으로 나눕니다.

| 대역 | 범위 | 주로 나타나는 것 |
| :--- | :--- | :--- |
| 서브동기 | 2 Hz ~ 0.5× | 오일 훨 · 풀림 · 벨트 |
| 1× 대역 | 0.5× ~ 1.5× | 불평형 · 정렬 불량 |
| 결함 대역 | 1.5× ~ 10× (최대 1 kHz) | 베어링 결함주파수 · 기어 |
| 고주파 | ~ 1 kHz | 초기 베어링 결함 |
| 초고주파 | 1 kHz 이상 | 충격성 · 마찰 |

대역마다 베이스라인과 같은 방식으로 정상 기준을 학습하고, **한계 대비 몇 배인지**로 등급을 매깁니다.

| 한계 대비 | 등급 |
| :--- | :--- |
| 1.0 ~ 1.5배 | 주의 |
| 1.5 ~ 3.0배 | 위험 |
| 3.0배 이상 | 심각 |

여러 대역이 동시에 넘어도 **설비당 이벤트 하나**로 합칩니다. 한 결함이 여러 대역에 동시에 나타나는 것이 정상이라, 대역마다 따로 알리면 알람이 몇 배로 늘어납니다. 어느 대역이 얼마나 넘었는지는 이벤트 상세에 함께 기록됩니다.

> 샘플레이트가 낮은 센서에서는 상위 대역이 측정 범위를 벗어나 학습되지 않습니다. 그 대역은 판정에서 제외되며, 화면에 "5개 중 4개 학습됨"처럼 표시됩니다.

### 등급 결정

**세 판정 중 가장 나쁜 것**이 그 태그의 등급이 됩니다. 무엇이 등급을 올렸는지도 함께 표시되므로, 등급이 올라간 이유를 화면에서 바로 알 수 있습니다.

ISO 존만 쓰면 고주파가 지배하는 센서에서 베어링이 나빠져도 화면이 계속 양호로 보입니다. 세 기준을 함께 쓰는 이유입니다.

## ③ 이벤트

판정 결과 중 **상태가 바뀐 순간만** 이벤트로 남습니다. 같은 상태가 유지되는 동안은 기록하지 않습니다.

| 유형 | 언제 생기는가 |
| :--- | :--- |
| **임계 초과** | 등급이 나빠졌을 때 |
| **상태 지속** | 나쁜 상태가 계속될 때, 설정한 재알림 주기마다 |
| **상태 개선** | 알람 수준에서는 벗어났지만 아직 양호는 아닐 때 |
| **정상 복귀** | 완전히 양호로 돌아왔을 때 |
| **베이스라인 이탈** | 평소 대비 한계를 넘었을 때 |
| **대역 이탈** | 특정 주파수 대역이 한계를 넘었을 때 |
| **대역 복귀** | 모든 대역이 한계 아래로 돌아왔을 때 |
| **신호 두절** | 데이터가 들어오지 않을 때 |

### 개선과 복귀의 차이

한 번의 이상 상황에서 좋아지는 과정은 두 단계로 나뉩니다.

| | 뜻 | 대응 |
| :--- | :--- | :--- |
| 상태 개선 | 급한 불은 껐다 | 우선순위 하향, 긴급 대응 해제 |
| 정상 복귀 | 완전히 정상이다 | 작업지시 종료 |

둘을 나누는 이유는 실무 대응이 다르기 때문입니다. 또 존 경계 근처에서 운전하는 설비는 완전한 양호에 좀처럼 도달하지 않는데, 그런 설비도 "개선됐다"는 신호는 받을 수 있어야 합니다.

각 단계는 한 번의 이상 상황마다 **한 건씩만** 기록됩니다. 심각 → 위험 → 주의 → 양호로 단계적으로 좋아져도 개선 1건, 복귀 1건입니다.

### 기록 규칙

- **양호가 계속되는 동안은 아무것도 기록하지 않습니다.** 나쁨에서 돌아온 정상 복귀만 1건 남습니다.
- **여전히 나쁜 상태로 좋아지는 중간 단계**(심각 → 위험 등)는 따로 기록하지 않습니다. 위의 상태 개선으로 대표됩니다.
- **처음 보는 태그가 이미 나쁘면 즉시 기록합니다.** 확인 시간을 기다리지 않습니다.
- **베이스라인·대역 이탈은 등급 변화와 무관하게** 판정됩니다. 넘어서는 순간 한 번 기록되고, 이탈 상태가 유지되는 동안 반복되지 않습니다.
- **이벤트는 자동으로 삭제되지 않습니다.** 이력도 데이터이므로 보존됩니다.

### 이벤트 값 읽기

이벤트 목록의 "지표값 vs 기준"은 유형에 따라 의미가 다릅니다.

| 유형 | 지표값 | 기준 |
| :--- | :--- | :--- |
| 임계 초과 · 상태 지속 · 개선 · 복귀 | 판정값 | 넘어선 존 경계 |
| 베이스라인 이탈 | 전대역 RMS | 학습된 한계 |
| 대역 이탈 · 복귀 | **한계 대비 배수** | 1 |

대역 이벤트만 배수로 표시됩니다. 대역마다 값의 크기가 달라 하나의 절대값으로 비교할 수 없기 때문입니다.

## ④ 알람이 바로 안 나는 경우

등급이 바뀌자마자 알람이 나가지는 않습니다. 방향에 따라 확인 시간을 요구합니다.

| | 설정 | 목적 |
| :--- | :--- | :--- |
| 나빠질 때 | 진입 확인 시간 | 순간 스파이크 무시 |
| 좋아질 때 | 복귀 유지 시간 | 경계 오르내림(플래핑) 방지 |

진입 확인 시간을 5분으로 두면 5분 미만의 스파이크는 의도적으로 무시됩니다. 알람이 안 났다면 이 설정을 먼저 확인하세요.

## 정지와 신호 두절

값이 갑자기 낮아졌다고 해서 좋아진 것은 아닙니다.

- **설비 정지** — 판정값이 평소의 20% 아래로 떨어지면 정지로 보고 판정을 **동결**합니다. 진동 결함은 스스로 낫지 않으므로, 설명되지 않는 하락은 대개 설비가 멈췄거나 센서를 잃은 것입니다. 이때 "정상 복귀" 알림이 나가면 설비가 고쳐진 줄 오해하게 됩니다. 동결 중에는 직전 상태를 유지하므로, 재가동하면 이전에 나빴다는 사실이 그대로 남아 있습니다.
- **신호 두절** — 새 데이터가 판정 주기의 여러 배가 지나도록 들어오지 않으면 두절로 보고 이벤트를 남깁니다. 그냥 건너뛰면 화면이 마지막 값을 들고 계속 정상으로 보이기 때문입니다.

## 베이스라인 학습

### 무엇을 배우는가

정상 운전 구간의 **평소 수준(μ)** 과 **평소 변동폭(σ)** 입니다. 학습 기간(1시간 / 6시간 / 24시간)을 고르고 학습을 실행하면 그 구간의 데이터로 기준이 만들어집니다.

추정에는 스파이크에 흔들리지 않는 중앙값 방식을 씁니다. 정상 운전 중에도 순간 충격은 섞이는데, 단순 평균은 그것까지 흡수해 기준을 부풀립니다.

### 자동으로 걸러지는 구간

학습 구간에 정지나 기동이 섞여 있으면 기준이 낮게 잡힙니다. 그래서 학습 전에 자동으로 제외합니다.

- **정지·아이들 구간** — 운전 수준의 20% 미만
- **기동·정지 과도 구간** — 값이 급격히 변하는 구간

학습에 성공해도 `제외 12 (정지 8 · 과도 4)`처럼 제외 내역이 표시됩니다. 남은 데이터로 학습했다는 뜻이며 정상입니다.

### 학습이 거부되는 경우

| 상황 | 안내 | 대응 |
| :--- | :--- | :--- |
| 표본 부족 | 정상 구간 표본이 최소 개수에 못 미침 | 학습 기간을 늘리거나 데이터가 더 쌓인 뒤 재시도 |
| 정지↔운전 두 수준 | 학습 구간 대부분이 정지 | 연속 운전이 대부분인 기간으로 다시 학습 |

두 번째는 특히 중요합니다. 정지 수준을 정상 기준으로 잡으면 **설비를 돌리기만 해도 이탈 알람이 터집니다.** 그래서 학습 자체를 거부합니다.

### 자동 재학습을 하지 않는 이유

학습한 지 오래되면 화면이 알려 주지만, 자동으로 갱신하지는 않습니다. 결함이 자라는 중에 재학습하면 **그 결함을 정상으로 흡수**해 버리기 때문입니다.

정비를 했거나 운전 조건이 바뀌었다면 그때 사람이 다시 학습시키는 것이 맞습니다.

### 태그를 지웠다 다시 만든 경우

학습값은 `테이블:태그` 이름을 키로 저장됩니다. 태그를 지워도 학습값은 남아 있어서, 나중에 **같은 이름으로 다른 설비를 붙이면 옛 기준이 그대로 적용**됩니다.

새 설비가 더 조용하면 이상을 영영 못 잡고, 더 시끄러우면 알람이 계속 터집니다. 화면에는 그냥 "학습됨"으로 보이므로 알아채기 어렵습니다.

데이터만으로는 같은 설비인지 알 수 없으므로 앱이 확인을 요청합니다. 판정 기준 화면에 **같은 설비 — 유지** / **다른 설비 — 초기화** 선택이 나타나며, 확인 전까지 그 태그의 베이스라인·대역 판정은 멈춥니다. ISO 존은 절대 기준이라 그동안에도 계속 동작합니다.

## 대역 에너지 추출

대역별 값은 원시 데이터를 주파수 분석해야 얻어지므로, 판정과는 **별도의 타이머**가 주기적으로 계산해 쌓습니다.

- 계산은 서버에서 이뤄집니다. 앱이 닫혀 있어도 추세가 이어집니다.
- 추출 주기(1분 ~ 1시간)가 짧을수록 표본이 빨리 쌓여 학습을 일찍 시작할 수 있습니다.
- 정지된 설비의 옛 구간을 긁지 않도록, 항상 그 태그의 최신 데이터 시각을 기준으로 계산합니다.

### 과거 데이터 채우기

학습에 필요한 표본이 쌓이려면 시간이 걸립니다. 이미 DB에 원시 데이터가 있다면 **과거 채우기**로 소급해 계산할 수 있습니다.

계산 방식이 타이머와 동일하므로 채운 값과 이후 쌓이는 값을 이어서 학습해도 됩니다. 진행 상황과 예상 소요 시간이 표시되고, 중간에 멈춰도 채운 만큼은 그대로 쓰입니다.

## 판정 지문

생성된 리포트에는 **판정 지문**이 함께 기록됩니다. 판정에 쓰인 임계값과 기준에서 계산된 짧은 문자열입니다.

두 리포트의 숫자가 다를 때 원인을 가릅니다.

- 지문이 **같다** → 판정 기준은 동일하고, **데이터가 달라진** 것
- 지문이 **다르다** → 그 사이 **판정 기준 설정이 바뀐** 것
