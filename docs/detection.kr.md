# 이상 판정 원리

**한국어** | [English](./detection.en.md)

이 문서는 앱이 **무엇을 재고, 어떤 기준으로 등급을 매기고, 언제 이벤트를 남기는지**를 설명합니다.

설정 화면의 각 항목과 알림 받는 법은 [알람과 이벤트](./alarms.kr.md)에 있습니다. 이 문서는 그 설정이 실제로 무엇을 바꾸는지 이해하려는 분을 위한 것입니다.

## 한 줄 요약

> **결함 패턴이 등급을 켜고, ISO 존이 그 높이를 정합니다.**
> 베어링 결함주파수 자리에 근거가 서지 않으면 진동이 아무리 높아도 등급은 양호입니다 —
> 대신 "진폭은 높다"는 사실을 화면이 따로 적습니다.

**상세분석과 상시감시가 같은 규칙을 씁니다.** 창 길이와 주기만 다릅니다.

## 전체 흐름

감시는 **두 개의 주기**로 돕니다. 하나는 빠르고 가볍고, 하나는 느리고 무겁습니다.

```
                     원시 진동 데이터
                            │
          ┌─────────────────┴─────────────────┐
          │                                   │
   판정 주기마다(기본 3초)             추출 주기마다(기본 10분)
    구간 RMS 하나                    FFT → 포락선 → 결함주파수 격자
          │                                   │
          ├── 운전 / 정지                     ├── 결함 패턴 (게이트)
          ├── 신호 두절                       ├── ISO 존   (높이) ← 같은 파형
          ├── 계측 이상                       └── 대역 에너지 (근거)
          └── 베이스라인 이탈 (근거)                    │
                    │                                  ▼
                    │                          등급 = 패턴이 켤 때만 오른다
                    │                                  │
                    └──── 판정 동결 ────────────────────┤
                          (정지·두절·계측 이상)          ▼
                                                두 회차 연속 확인
                                                       │
                                                       ▼
                                                이벤트 기록 → 알림
```

**등급 이벤트는 오른쪽 축에서만 나옵니다.** 왼쪽 축은 판정을 **멈추는** 일(정지·두절·계측 이상)과 **근거를 채우는** 일, 그리고 감시 상태 이벤트(신호 두절·계측 이상·계측 복귀)만 합니다.

### 왜 두 주기인가

| | 빠른 축 | 느린 축 |
| :--- | :--- | :--- |
| 계산 | 구간 RMS 1회 | 원시 파형 → FFT → 포락선 |
| 무게 | 가벼움 | 무거움(원시 파형을 주파수 분석) |
| 답하는 것 | "지금 돌고 있나 · 신호가 오나" | "무엇이 상했나" |

결함 패턴은 원시 파형을 주파수 분석해야 해서 몇 초마다 돌리기엔 너무 무겁습니다. 태그가 많으면 계산이 주기를 넘어섭니다.

그리고 **그럴 이유도 없습니다.** 베어링 결함은 시간·일 단위로 자랍니다. 초 단위로 터지는 사고는 10분 주기든 10초 주기든 어차피 사후입니다 — 그건 감시가 아니라 보호계전기의 일입니다.

### 왜 등급 이벤트를 한쪽 축에서만 내는가

베이스라인·대역은 이벤트를 내지 않습니다. 두 가지 이유입니다.

**① 시간축이 다릅니다.** 베이스라인 판정값은 빠른 축의 구간 RMS인데 등급은 느린 축의 결함 패턴이 정합니다. 둘을 같은 이벤트 흐름에 섞으면 **이벤트 시각이 무엇을 가리키는지 흐려지고**, 재알림 간격에도 두 주기가 뒤섞입니다.

**② 축이 늘면 오경보가 곱해집니다.** 대역은 여러 계열을 각각 한계와 대 보고 하나라도 넘으면 켜는 구조라 그 자체로 오탐이 많습니다.

두 축의 값은 **사라지지 않고 근거로 남습니다.** 카드와 근거표에 그대로 표시되고, "어느 대역이 움직였나"로 원인을 좁히는 데 쓰입니다. 알림만 안 갑니다.

> **대가는 분명합니다.** 베이스라인은 오탐이 가장 적은 축인데, 알림에서 빠졌습니다. 베어링 결함이 아닌 원인(불평형·정렬불량·풀림)으로 진폭만 오르는 경우는 **사람이 화면에서 봐야** 합니다. 아래 [한계와 대안](#한계와-대안)을 보십시오.

## 빠른 축의 판정값 — 구간 RMS

빠른 축의 판정값은 **한 구간 전체의 RMS 값 하나**입니다. 가장 최근에 들어온 한 점이 아닙니다.

진동은 순간마다 출렁이므로 한 점으로 판정하면 값이 계속 흔들립니다. 대신 "직전 10초 구간"처럼 일정 길이의 데이터를 하나의 실효값으로 합쳐서 봅니다.

여기서 **RMS 구간**과 **판정 주기**는 다른 설정입니다.

| 설정 | 뜻 | 기본값 | 설정 위치 |
| :--- | :--- | :--- | :--- |
| RMS 구간 | 얼마나 긴 데이터를 하나로 볼지 | 직전 10초 | 알람 설정 |
| 판정 주기 | 얼마나 자주 판정할지 | 3초마다 | 알람 설정 |
| 추출 주기 | 결함 패턴을 얼마나 자주 계산할지 | **10분마다** | 판정 기준 → 대역 에너지 추세 |

앞의 둘은 RMS 구간 3초~1시간, 판정 주기 1초~1분에서 고릅니다. 추출 주기는 10분 · 30분 · 1시간 중에서 고르며, 태그가 많아 한 회차 계산이 길면 그보다 짧은 주기는 고를 수 없게 막힙니다.

구간이 **길수록** 짧은 출렁임이 하나의 상태로 합쳐집니다 — 반응이 느려지는 대신 안정됩니다. 구간이 판정 주기보다 짧으면 그 사이 데이터가 판정에 들어가지 않으므로 화면이 경고합니다.

부하가 주기적으로 변하는 설비라면 그 변동 주기보다 긴 구간을 잡는 것이 좋습니다. 짧으면 부하 변화 자체가 정지·이탈로 잡힙니다.

## 결함 패턴 — 등급을 켜는 축

### 무엇을 보는가

베어링은 상한 자리에 따라 **구르는 주기가 정해져 있습니다.** 회전수와 베어링 기하(볼 개수·볼 지름·피치 지름·접촉각)를 알면 그 주기를 계산할 수 있습니다.

| 이름 | 무엇 | 대략 |
| :--- | :--- | :--- |
| **BPFO** | 외륜 결함 | 회전주파수 × 볼수 × 0.4 |
| **BPFI** | 내륜 결함 | 회전주파수 × 볼수 × 0.6 |
| **BSF** | 구름체 결함 | 회전주파수 × 2~3 |
| **FTF** | 케이지 | 회전주파수 × 0.4 |

결함이 있으면 그 주파수와 배음(2×·3×·4×) 자리에 에너지가 섭니다. **그 격자와 실제 스펙트럼을 대조**하는 것이 이 축입니다.

### 어떻게 보는가 — 포락선

결함 충격은 **저주파 진동으로 직접 나타나지 않습니다.** 충격이 베어링·하우징의 고주파 공진을 때리고, 그 공진이 결함 주기로 **얻어맞은 만큼 커졌다 작아집니다**. 신호는 고주파인데 정보는 그 크기 변화(포락선)에 있습니다.

```
   원시 파형 → 1~5 kHz 대역만 남김 → 크기 변화(포락선) 추출 → 저주파 스펙트럼
                     (대역통과)                                (여기에 격자를 댄다)
```

**대역은 1~5 kHz로 고정**입니다. 가장 충격적인 대역을 자동으로 고르는 방식(커토그램)은 공개 데이터 검증에서 안티에일리어싱 잡음이나 인버터 전기 성분 대역에 붙잡혀 검출이 크게 떨어졌습니다. 그래서 커토그램은 상세분석의 **대역별 충격성** 차트에 참고로만 보여 주고 판정에는 쓰지 않습니다.

샘플레이트가 낮아 1~5 kHz 대역이 성립하지 않는 센서는 전대역으로 복조합니다. 이 경우 근거가 약하며 조기 베어링 결함은 잡히지 않는다는 안내가 카드 툴팁에 붙습니다.

> **대형 설비 주의** — 1~5 kHz는 검증에 쓴 소형~중형 시험대의 공진 대역입니다. 실제로 이 대역에 자주 걸리는 것은 **가속도계 마운팅 공진**(부착 방식에 따라 수 kHz)이고, 베어링 링 자체의 굴곡 모드는 설비가 커질수록 **낮아집니다**. 큰 저속 설비에서는 대역이 안 맞을 수 있는데, 검증 데이터에 그런 설비가 없어 **어느 쪽으로 틀리는지 아직 모릅니다.**

### 언제 켜지는가

격자 자리의 에너지가 주변 잡음 수준 대비 몇 배인지로 점수(격자 점수)를 냅니다. 그 점수가 채택 임계를 넘으면 게이트가 켜집니다.

| | 창 길이 | 채택 임계 |
| :--- | :--- | :--- |
| **상세분석** | 100회전 | 4.0 |
| **상시감시** | **25회전** | **3.0** |

감시가 짧은 창을 쓰는 이유는 서버 계산 비용입니다. 창이 짧으면 점수가 전반적으로 낮게 나오므로 임계도 함께 낮춥니다. 그 대가로 감시는 상세분석보다 조금 덜 잡습니다(공개 데이터 기준 검출 66% → 59%).

감시는 **신호를 띄우는 역할**이고 확정은 상세분석이 100회전으로 합니다 — 놓치지만 않으면 짧아도 됩니다.

### 판정할 수 없는 경우

회전수나 베어링 기하를 모르면 격자를 만들 수 없습니다. 이때 등급은 **오르지 않습니다** — 그런데 그건 "정상"이 아니라 "판정 못 함"입니다.

화면이 이것을 숨기지 않습니다. 모니터링 카드는 등급 대신 **판정 보류**(판정 못 함)로, 상세분석은 "판정 기준 n/N (… 미적용)"으로 표시하고, 설비 정보 화면은 **판정 불가** 배지로 알립니다. 저널(sleeve) 베어링도 구름요소가 없어 여기에 해당합니다.

> **회전수를 추정하지 않습니다.** 틀린 회전수로 격자를 세우면 조용히 틀린 등급이 나오기 때문입니다.

## ISO 존 — 높이를 정하는 축

ISO 10816 규격이 정한 진동 심각도 존(A 양호 → D 심각)입니다. 설비 Class(설비 정보)에 따라 경계값이 달라집니다.

| Class | 양호↔주의 | 주의↔위험 | 위험↔심각 |
| :--- | ---: | ---: | ---: |
| Class I (소형 ≤15kW) | 0.71 | 1.8 | 4.5 |
| Class II (중형 15–75kW) | 1.12 | 2.8 | 7.1 |
| Class III (대형·강성 기초) | 1.8 | 4.5 | 11.2 |
| Class IV (대형·연성 기초) | 2.8 | 7.1 | 18.0 |

단위는 mm/s(속도 RMS)이며 ISO 10816 기준값입니다. 값은 판정 기준 화면에서 직접 바꿀 수 있습니다. Class를 비워 두면 Class II로 판정합니다.

**가속도(g)·변위(μm) 센서도 값을 속도로 환산해 위 Class 경계로 판정합니다.** 판정 기준 화면의 g·μm 행(기본 0.5/1.0/2.0 g, 12/25/50 μm)은 규격이 정의한 값이 아닌 일반 참고값으로, 그 단위 센서의 RMS 추이 기준선과 기간 통계 표시에만 쓰입니다. 그래서 단위를 비워 두면(속도로 간주) 가속도·변위 센서의 등급 높이가 틀어집니다.

> **대역제한** — ISO 존 판정은 10–1000 Hz 구간만 남겨서 잽니다. 규격의 존 경계 자체가 그 대역에서 측정한 값으로 정해진 숫자이기 때문입니다. 고주파 성분이 많은 센서에서는 전대역 값과 ISO 값이 상당히 다를 수 있는데(카드 숫자에 마우스를 올리면 둘 다 보입니다), 이 경우 존 판정에 쓰는 쪽이 규격에 맞는 값입니다.

### ISO를 독립 축으로 두지 않는 이유

ISO 존만으로 경보를 켜면, 공개 데이터 383건으로 검증했을 때 정상 설비의 69%가 경보로 잡혔습니다. 결함 패턴을 게이트로 쓰면 3%입니다(검출은 조금 줄어듭니다). 머신 클래스를 잘못 골라도 오탐이 거의 흔들리지 않는 것도 덤입니다 — ISO가 경보를 켜지 않으니까요.

이 69%는 실기 설비의 오탐률이 아니라, 검증에 쓴 가속수명시험대의 특성 때문에 나온 값입니다. 자세한 것은 [이 도구가 하는 일과 하지 않는 일](./scope.kr.md#축을-합치면-어떻게-되는가)에 있습니다.

### 높이를 재는 파형

감시에서 ISO 값은 **결함 패턴을 잰 바로 그 파형**에서 잽니다. 빠른 축의 최신 ISO를 쓰면 등급이 몇 초마다 움직여, 10분 주기인 패턴과 시간축이 어긋납니다.

패턴 계산 때 ISO를 못 쟀으면 빠른 축 값으로 물러섭니다 — 등급을 0으로 떨어뜨리지는 않습니다.

## 근거 축 — 등급을 안 만드는 두 가지

### 베이스라인 — 평소 대비

설비가 정상일 때의 상태를 학습해 두고, 거기서 얼마나 벗어났는지 봅니다.

```
한계 = 평소 수준(μ) + k × 평소 변동폭(σ)
```

절대값이 아직 양호 존이어도 **평소보다 뚜렷하게 올라갔으면** 잡아냅니다. `k`는 민감도입니다 — 작을수록 민감하고, 크면 확실할 때만 반응합니다.

평소 변동이 거의 없는 아주 안정된 설비에서는 한계가 평소 수준에 지나치게 붙을 수 있어, **최소한 평소의 +20%는 올라야** 이탈로 봅니다.

이탈해도 **등급은 오르지 않고 이벤트도 나지 않습니다.** 카드(숫자에 마우스)와 근거표에 "평소 대비 급증"으로 표시됩니다. 학습 방법은 [첫 설정 › 베이스라인 학습](./first-setup.kr.md#베이스라인-학습)에 있습니다.

### 대역 에너지 — 주파수 대역별

전체 RMS로는 안 보이는 변화를 잡습니다. 베어링 결함이 자라도 전체 진동은 거의 안 움직이는데, 그 결함이 나타나는 주파수 대역만 보면 몇 배로 뜁니다.

대역은 회전주파수(1×)를 기준으로 다섯 구간으로 나눕니다. 이 중 초고주파는 1~2 · 2~4 · 4~8 · 8 kHz+ 네 대역으로 세분되어, 실제로 쌓이는 주파수 대역은 8개입니다.

1×는 추출할 때마다 파형에서 실측합니다. 입력 RPM **±5% 안의 봉우리만** 1×로 보고, 계통주파수(설정의 50/60 Hz) 봉우리는 제외하며, 못 찾으면 입력 RPM을 씁니다. 상세분석의 실측 1×와 같은 규칙입니다. 범위를 더 넓히면 벨트로 이어진 모터처럼 다른 회전체의 봉우리를 1×로 잡아 대역 경계가 통째로 밀립니다. 그래서 입력 RPM이 실제와 5% 넘게 다르면 대역 경계도 틀립니다 — RPM은 정격 회전수로 정확히 입력하십시오.

| 대역 | 범위 | 주로 나타나는 것 |
| :--- | :--- | :--- |
| 서브동기 | 2 Hz ~ 0.5× | 오일 훨 · 풀림 · 벨트 |
| 1× 대역 | 0.5× ~ 1.5× | 불평형 · 정렬 불량 |
| 결함 대역 | 1.5× ~ 10× (최대 1 kHz) | 베어링 결함주파수 · 기어 |
| 고주파 | ~ 1 kHz | 초기 베어링 결함 |
| 초고주파 | 1 kHz 이상 (1~2 · 2~4 · 4~8 · 8 kHz+) | 충격성 · 마찰 |

대역마다 베이스라인과 같은 방식으로 정상 기준을 학습하고, **한계 대비 몇 배인지**를 근거표에 적습니다. 마운팅 방식의 유효 상한을 넘는 대역의 이탈은 **(잠정)** 으로 표시됩니다 — 값이 오른 것은 사실이지만 설비 진동인지 센서 부착부 공진인지 구분할 수 없다는 뜻입니다.

> 샘플레이트가 낮은 센서에서는 상위 대역이 측정 범위를 벗어나 학습되지 않고, 베어링 품번이 없으면 포락선 결함주파수 계열이 쌓이지 않습니다. 학습되지 않은 계열은 빠지며, 화면에 "4/9 계열 학습됨"처럼 표시됩니다.

### 왜 학습 축을 게이트에 안 넣는가

상세분석에서 특히 중요합니다. 학습 축을 게이트에 넣으면 **같은 태그가 학습 여부에 따라 다른 등급**을 내고, 검증에서도 오탐이 크게 늘었습니다.

일회성 분석은 "지금 이 신호가 무엇처럼 보이나"에 답하는 도구이므로 학습 상태에 매이면 안 됩니다.

### Crest는 등급을 올리지 않습니다

Crest(첨두/실효 비)도 등급에 들어가지 않습니다. 진폭이 낮은 구간에서는 분모가 작아 스파이크 하나에도 크게 튀기 때문입니다.

대신 **판정 문구**에 반영됩니다. 진폭은 정상인데 Crest가 기준을 넘으면 판정이 "정상 운전"이라고 단정하지 않습니다. 기준은 잡음만으로는 거의 넘지 않는 선으로 잡혀 있고, 기간이 길어 분·시간 단위로 묶인 데이터로 볼 때는 충격성을 판단하지 않습니다(부하 변동만으로 최댓값이 커지기 때문).

낮은 RMS에 높은 Crest는 **국부 결함 초기의 시그니처이면서 동시에 계측 스파이크(ESD·케이블·접촉)의 시그니처**이기도 합니다. 이 값 하나로는 갈리지 않으므로 등급을 움직이지 않고 사실만 적습니다. 둘을 가르는 것은 충격이 **반복되는지**입니다 — 포락선에서 결함주파수에 정렬되면 결함, 흩어져 있으면 계측 쪽입니다. 권고 문구가 이 확인을 지시합니다.

계측 이상(클리핑·DC 드리프트 등)이 걸린 상태에서는 그 경고 문구가 우선합니다. 이미 계측 확인을 지시하고 있기 때문입니다.

## 등급 결정

```
등급 = 결함 패턴이 켜졌는가?  →  아니오 : 양호
                              →  예     : max(주의, ISO 존 등급)
```

패턴이 켜졌는데 ISO가 양호면 **주의**입니다. 원인을 지목해 놓고 등급이 양호로 남으면 화면이 스스로 어긋나기 때문입니다.

등급을 안 올린 축도 **사실은 남깁니다.** 화면이 "양호"만 말하면 거짓이 됩니다.

| 상황 | 등급 | 화면 문구 |
| :--- | :--- | :--- |
| 패턴 ○ · ISO 위험 | 위험 | 외륜 결함 근거 · 진폭 위험 존 |
| 패턴 ○ · ISO 양호 | **주의** | 외륜 결함 근거 · 진폭은 아직 낮음 |
| 패턴 ✕ · ISO 위험 | **양호** | **진폭이 높으나 베어링 결함 근거 없음** — 불평형·정렬·풀림 확인 |
| 패턴 ✕ · 베이스라인 이탈 | 양호 | 평소 대비 급증 |
| 패턴 ✕ · 대역 이탈 | 양호 | 고주파 대역 이탈 |
| 회전수·기하 미입력 | 매기지 않음 | **판정 보류(판정 못 함)** |

세 번째 줄이 이 설계의 핵심 트레이드오프입니다. **베어링이 아닌 고장은 등급이 안 오릅니다** — 이 도구는 베어링 진단 도구이고, 불평형·정렬불량은 위상(타코)·축방향 채널 없이는 원리적으로 판별할 수 없기 때문입니다. 숨기지는 않고 문구로 밝힙니다.

## 이벤트

판정 결과 중 **상태가 바뀐 순간만** 이벤트로 남습니다. 같은 상태가 유지되는 동안은 기록하지 않습니다.

| 유형 | 언제 생기는가 | 어느 축 |
| :--- | :--- | :--- |
| **관찰** | 양호에서 처음 벗어난 회차 — **확정 전, 알림 안 감** | 느린 축 (패턴) |
| **임계 초과** | 같은 등급이 **두 회차 연속**이라 확정됐을 때 | 느린 축 (패턴) |
| **상태 지속** | 나쁜 상태가 계속될 때, 재알림 주기마다 | 느린 축 (패턴) |
| **상태 개선** | 알람 수준에서는 벗어났지만 아직 양호는 아닐 때 | 느린 축 (패턴) |
| **정상 복귀** | 완전히 양호로 돌아왔을 때 | 느린 축 (패턴) |
| **계측 이상** | 클리핑 · DC 드리프트 · 플랫라인 등이 1분 이어질 때 | 빠른 축 |
| **계측 복귀** | 계측 이상이 풀리고 정상이 5분 이어질 때 | 빠른 축 |
| **신호 두절** | 데이터가 들어오지 않을 때 | 빠른 축 |

아래 세 개는 진동 등급이 아니라 **"감시가 제대로 되고 있나"**를 알립니다. 화면이 마지막 값을 들고 계속 정상으로 보이는 것이 가장 나쁜 실패이기 때문입니다.

**베이스라인·대역은 이벤트를 내지 않습니다.** 상태는 계속 추적되어 근거표에 표시됩니다.

### 개선과 복귀의 차이

한 번의 이상 상황에서 좋아지는 과정은 두 단계로 나뉩니다.

| | 뜻 | 대응 |
| :--- | :--- | :--- |
| 상태 개선 | 급한 불은 껐다 | 우선순위 하향, 긴급 대응 해제 |
| 정상 복귀 | 완전히 정상이다 | 작업지시 종료 |

둘을 나누는 이유는 실무 대응이 다르기 때문입니다. 또 존 경계 근처에서 운전하는 설비는 완전한 양호에 좀처럼 도달하지 않는데, 그런 설비도 "개선됐다"는 신호는 받을 수 있어야 합니다.

각 단계는 한 번의 이상 상황마다 **한 건씩만** 기록됩니다. 심각 → 위험 → 주의 → 양호로 단계적으로 좋아져도 개선 1건, 복귀 1건입니다.

### 기록 규칙

- **양호가 계속되는 동안은 아무것도 기록하지 않습니다.** 나쁨에서 돌아온 정상 복귀만 1건 남습니다.
- **여전히 나쁜 상태로 좋아지는 중간 단계**(심각 → 위험 등)는 따로 기록하지 않습니다. 상태 개선으로 대표됩니다.
- **처음 보는 태그가 이미 나쁘면** 그 회차에 `관찰`이 바로 기록되고, 다음 회차에도 같으면 확정됩니다. 첫 회차에 바로 확정하지 않는 것은 감시를 켜는 순간 나쁜 태그 전부가 한꺼번에 알람을 내지 않게 하기 위해서입니다.
- **이벤트는 자동으로 삭제되지 않습니다.** 이력도 데이터이므로 보존됩니다.

### 이벤트 값 읽기

등급 이벤트의 값은 **등급의 높이를 정한 ISO 값**(결함 패턴을 잰 바로 그 파형에서 잰 값)입니다. 하지만 ISO 값은 등급을 켠 축이 아니므로(게이트는 결함 패턴입니다), 값만 보면 오해할 수 있습니다. "왜 이 등급인가"는 결함 패턴 근거가 답합니다.

| 어디서 | 무엇이 보이나 |
| :--- | :--- |
| 모니터링 이벤트 목록의 '상세' 칸 | 속도 센서: `ISO 값 · 기준(넘어선 존 경계)` / 가속도·변위 센서: `원본 단위 값 · ISO <존> 구간 · 결함 패턴 <부위>` / 신호 두절: `N분 무수신` / 계측 이상·복귀: 사유(예: `플랫라인`, 설명은 마우스를 올리면 표시) |
| 내보내기(CSV·JSON)의 '상세' 열과 알림 문구 | 결함 패턴의 격자 점수 · 부위 · 회차, 계측 이상의 사유 |

내보내기 파일의 '상세' 예:

```
관찰       격자 3.2 · 외륜(BPFO) · 1회차 — 확정 전
임계 초과   격자 3.2 · 외륜(BPFO) · 2회 연속 확정
상태 지속   격자 4.1 · 지속 재알림
정상 복귀   격자 2.2 · 4시간 20분 만에 복귀
```

## 확정 — 두 회차 연속

등급이 바뀌자마자 알람이 나가지는 않습니다. **같은 판정이 두 회차 연속**이라야 확정됩니다. 나빠질 때도, 좋아질 때도 같습니다.

```
회차 1   격자 3.2 → 주의    관찰 이벤트 · 알림 안 감
회차 2   격자 3.2 → 주의    임계 초과 · 알림 발송
회차 3   격자 2.1 → 양호    (아직 복귀 아님)
회차 4   격자 2.0 → 양호    정상 복귀 · 알림 발송
```

한 회차라도 되돌아가면 연속이 끊기고 처음부터 다시 셉니다. 판정이 추출 주기로 돌기 때문에 확정은 분이 아니라 **회차**로 셉니다.

### 두 회차인 이유

공개 전 수명시험 데이터를 실제 감시 주기로 재생해 보니, 결함은 대개 **"첫 단발 → 긴 공백 → 연속 구간"** 모양이었고, 첫 단발에 현장을 가면 아무것도 찾지 못했습니다. 같은 성질의 단발은 건전한 베어링에서도 자주 났습니다.

두 회차 연속을 요구하면 단발까지 확정할 때보다 오경보가 크게 줄고, 경보 시점은 오히려 진짜 신호가 시작되는 곳에 맞춰집니다. 숫자는 [이 도구가 하는 일과 하지 않는 일 › 시간축 성적](./scope.kr.md#시간축-성적--전-수명-시험)에 있습니다.

> **단발도 흔적은 남습니다.** 확정에 못 간 단발은 `관찰` 이벤트로 이력에 남습니다. 알림만 나가지 않습니다.

### 계측 이상은 시간 기준 그대로

신호 두절·클리핑·DC 드리프트는 **빠른 축**에서 판정하므로 회차 개념이 없습니다. 스파이크 한 번에 "센서 고장"이 나가지 않도록 1분 지속을 요구하고, 복귀는 5분을 요구합니다. 설정으로 바꾸지 않습니다.

### DC — 일정한 DC는 막지 않습니다

MEMS 가속도계의 수직축(중력 1 g)이나 근접 변위센서(갭 전압)는 정상 상태에서도 평균이 진동 폭보다 훨씬 큽니다. 판정값은 대역 필터·평균 제거를 거쳐 이 DC에 영향을 받지 않으므로, **일정한 DC는 판정을 막지 않고** 상세분석과 리포트에 참고로만 적습니다("DC 성분" 회색 안내 — 경고 상자와 별개).

막는 것은 **1초 평균이 흔들릴 때**입니다(평균의 흔들림이 진동 폭의 절반을 넘어 판정 RMS가 부풀 정도). 센서 바이어스·케이블 이상이나 자석 마운트가 돌아 중력 성분이 바뀌는 경우입니다.

- 회전수가 있고, 1초에 10회전 이상(600 rpm 이상)일 때만 봅니다. 저속기는 실제 진동이 1초 평균을 흔들기 때문입니다.
- 회전당 샘플이 4개 미만인 느린 값 태그(초당 몇 번 찍히는 트랜스미터 값 등)는 보지 않습니다. 이런 태그는 애초에 파형 분석 대상이 아닙니다.

## 정지와 신호 두절

값이 갑자기 낮아졌다고 해서 좋아진 것은 아닙니다.

- **설비 정지** — 판정값이 평소 운전 수준의 20% 아래로 떨어지면 정지로 보고 판정을 **동결**합니다. 진동 결함은 스스로 낫지 않으므로, 설명되지 않는 하락은 대개 설비가 멈췄거나 센서를 잃은 것입니다. 이때 "정상 복귀" 알림이 나가면 설비가 고쳐진 줄 오해하게 됩니다. 동결 중에는 직전 상태를 유지하므로, 재가동하면 이전에 나빴다는 사실이 그대로 남아 있습니다. 카드에는 **정지** 배지가 붙습니다.
- **신호 두절** — 새 데이터가 판정 주기의 6배(최소 1분) 넘게 들어오지 않으면 두절로 보고 이벤트를 남깁니다. 카드에는 **신호 두절** 배지가 붙고 그래프가 흐려집니다.

## 표본이 모자라는 태그

결함 패턴은 **회전수 기준의 표본 수**로 창을 잡습니다 — 시간이 아닙니다.

타임스탬프가 성긴 태그(재생 데이터·간헐 수집)는 같은 시간 안에 들어온 표본이 적습니다. 이 경우 창을 넓혀 다시 읽고(최대 2회), 그래도 표본이 모자라면 그 회차의 패턴 판정을 건너뜁니다. 넘치면 최신 쪽만 씁니다 — 창이 길어지면 운전 상태가 섞이기 때문입니다.

건너뛴 회차는 카드에 **판정 보류**(결함 패턴 측정 실패)로 표시되고 직전 등급이 유지됩니다. 조용히 "양호"로 보이지 않게 하기 위해서입니다.

## 베이스라인 학습

정상 운전 구간의 **평소 수준(μ)** 과 **평소 변동폭(σ)** 을 배웁니다. 스파이크에 흔들리지 않는 중앙값 방식을 쓰고, 정지·기동 구간은 자동으로 제외하며, 정지가 대부분인 구간은 학습을 거부합니다.

학습은 **자동으로 다시 하지 않습니다.** 결함이 자라는 중에 재학습하면 그 결함을 정상으로 흡수해 버리기 때문입니다. 정비를 했거나 운전 조건이 바뀌었다면 그때 사람이 다시 학습시키는 것이 맞습니다.

같은 이름으로 다른 설비를 붙인 경우의 확인(같은 설비 — 유지 / 다른 설비 — 초기화), 학습이 거부되는 경우 등 자세한 내용은 [첫 설정 › 베이스라인 학습](./first-setup.kr.md#베이스라인-학습)에 있습니다. 확인 전까지는 그 태그의 베이스라인·대역 근거만 멈추고, 결함 패턴과 ISO 존은 학습이 필요 없으므로 계속 동작합니다.

## 대역 에너지 추출

대역별 값은 원시 데이터를 주파수 분석해야 얻어지므로, **서버의 대역 추출 타이머**가 추출 주기마다 계산해 쌓습니다.

- 계산은 서버에서 이뤄집니다. 앱이 닫혀 있어도 추세가 이어집니다.
- 정지된 설비의 옛 구간을 긁지 않도록, 항상 그 태그의 최신 데이터 시각을 기준으로 계산합니다.
- 결함 패턴은 같은 주기로 재지만 대역 추출과는 별개입니다. 앱 감시에서는 앱이, 서버 상시 감시에서는 서버 감시 타이머가 잽니다. **대역 추출을 꺼도 등급 판정은 계속됩니다.**

### 과거 데이터 채우기

학습에 필요한 표본이 쌓이려면 시간이 걸립니다. 이미 DB에 원시 데이터가 있다면 **과거 데이터 채우기**로 소급해 계산할 수 있습니다.

계산 방식이 타이머와 동일하므로 채운 값과 이후 쌓이는 값을 이어서 학습해도 됩니다. 진행 상황과 예상 소요 시간이 표시되고, 중간에 멈춰도 채운 만큼은 그대로 쓰입니다.

## 상세분석과 감시의 차이

같은 규칙인데 **창·주기·시점**이 다릅니다.

| | 상세분석 | 상시감시 |
| :--- | :--- | :--- |
| 등급 공식 | 패턴이 켜고 ISO가 높이 | **동일** |
| 패턴 창 | 100회전 | 25회전 |
| 채택 임계 | 4.0 | 3.0 |
| 언제 | 사람이 기간을 고를 때 | 추출 주기마다 자동 |
| 어느 시점 | 기간 안 여러 지점(최대 8곳) 중 **가장 나쁜 곳** | 지금 |
| 학습 필요 | 없음 | 없음 (근거 표시에만) |

### 왜 상세분석은 여러 곳을 재는가

기간의 **끝**만 재면 그 순간의 상태가 기간 전체를 대표하게 됩니다. 실제로 외륜이 파손된 베어링에서, 선택한 창의 끝이 이미 정지 구간이라 등급이 양호로 나온 사례가 있었습니다.

그래서 기간을 나눠 각 지점에서 판정하고 **가장 나쁜 것**을 씁니다. 데이터가 없는 지점은 앞으로 당겨 붙이고 중복은 제거합니다. 어느 지점이 선택됐는지는 등급 옆 "판정 기준 시각"에 표시됩니다.

"1시간을 고르면 그 1시간 중 가장 상태가 나빴던 순간"이 등급이 됩니다 — 전 기간의 최악이 아닙니다.

## 판정 지문

생성된 리포트에는 **판정 지문**이 함께 기록됩니다. 판정에 쓰인 임계값과 기준에서 계산된 짧은 문자열입니다.

두 리포트의 숫자가 다를 때 원인을 가립니다.

- 지문이 **같다** → 판정 기준은 동일하고, **데이터가 달라진** 것
- 지문이 **다르다** → 그 사이 **판정 기준 설정이 바뀐** 것
