# 이 도구가 하는 일과 하지 않는 일

> **사람의 진단을 대체하지 않습니다.**
> 진단과 진단 사이의 공백을 메우고, 점검 순서를 매기고, 점검자가 볼 스펙트럼을 미리 띄워 둡니다.

ISO 18436 자격 체계로 경계를 그으면 이렇습니다 — **Category I(선별·데이터 수집)을 자동화하고,
Category II(고장 진단)의 진입 근거를 인쇄합니다. 확정은 사람이 합니다.**

아래 숫자는 전부 공개 데이터셋 실측입니다. 검출률은 **오탐률·모집단과 짝으로만** 적습니다 —
그 셋 중 하나라도 빠진 숫자는 비교가 불가능합니다.

---

## 무엇을 재는 도구인가

**베어링 진단 도구입니다.** 등급은 베어링 결함주파수 자리에 근거가 설 때만 오릅니다.

진동이 높다는 사실만으로는 등급이 오르지 않습니다 — 그건 화면에 따로 적힙니다. 불평형·정렬불량·풀림처럼 베어링이 아닌 원인은 **판정하지 않고**, 위상(타코)·축방향 채널 없이는 원리적으로 판별할 수 없기 때문에 앞으로도 판정하지 않습니다.

이 선택의 근거는 아래 [축을 합치면 어떻게 되는가](#축을-합치면-어떻게-되는가)에 있습니다.

## 두 가지 모드

| | 묻는 것 | 창 | 언제 |
| :--- | :--- | :--- | :--- |
| **상세분석** (일회성) | "이 신호가 무엇처럼 보이나" | 100회전 | 사람이 기간을 고를 때 |
| **상시감시** | "이 설비가 나빠지고 있나" | 25회전 | 10분마다 |

**두 모드 모두 학습이 필요 없습니다.** 등급을 만드는 두 축(결함 패턴·ISO 존)이 절대 기준이기 때문입니다. 베이스라인·대역은 학습이 필요하지만 **등급도 알림도 만들지 않고 근거로만** 쓰입니다.

**리드타임 숫자는 상시감시에서만 나옵니다.** 일회성 분석에는 시간 흐름이 없습니다.

> 학습 기간에 **결함이 이미 진행 중이면 그 결함이 정상 기준이 됩니다.** 자동 필터가 걸러 주지 못하는 부분이라, 학습 구간은 정비 이력과 대조해 사람이 골라야 합니다. 다만 이제 학습 축은 등급을 만들지 않으므로, 학습이 틀려도 **오경보로 이어지지는 않습니다** — 근거 표시만 틀립니다.

## 스냅샷 성적 — 383 케이스, 공개셋 4종

CWRU · MFPT · Paderborn · XJTU-SY. 기하(볼수·볼경·피치경·접촉각)가 1차 출처에
공개된 것만 골랐습니다.

| | 결과 |
| :--- | :--- |
| **정상 오탐** | **3/100 (3%)** |
| **결함 검출** | **188/283 (66%)** |
| 검출된 것 중 부위 적중 | 157/174 |

**"검출된 것 중 90%"를 단독으로 인용하면 안 됩니다** — 채택이 보수적일수록 좋아지는 조건부 값입니다.
사용자에게 실제로 남는 것은 **결함 셋 중 하나에서 부위까지 맞히는 정도**입니다.

부위별로는 **외륜이 가장 잘 서고, 내륜이 중간, 구름체는 부위를 말하지 않습니다.**

> **스냅샷과 시간축이 다르게 답하는 항목이 있습니다.** 구름체는 스냅샷 한 장에서는 사실상 못 잡지만,
> 전 수명 시험에서는 **잔여 72%(약 25일) 남기고 잡혔습니다**(NASA IMS Set 1 B4).
> 묻는 것이 다르기 때문입니다 — "이 한 장에서 구름체라고 **이름 붙일 수 있나**"는 기하가 겹쳐 안 되고,
> "이 베어링이 **나빠지고 있나**"는 됩니다. 부위를 못 말해도 이상은 섭니다.

### 축을 합치면 어떻게 되는가

같은 383 케이스에서 축별로 갈라 재면 이렇습니다
(학습 두 축은 같은 데이터셋의 다른 정상 케이스로 학습하는 leave-one-out).

| 축 | 단독 오탐 | 단독 검출 |
| :--- | :--- | :--- |
| **결함 패턴** | **3/100 (3%)** | 183/283 (65%) |
| **베이스라인** | **0/100 (0%)** | 79/283 (28%) |
| 대역 | 13/100 (13%) | 117/283 (41%) |
| **ISO 존** | **69/100 (69%)** | 104/283 (37%) |
| **네 축을 OR로 묶으면** | **69/100 (69%)** | 209/283 (74%) |
| **현행 — 패턴이 게이트, ISO가 높이** | **3/100 (3%)** | **188/283 (66%)** |

예전에는 네 축의 **최댓값**을 등급으로 썼습니다. 최댓값 방식에서는 축이 늘면 등급이 올라가기만 하므로, ISO 축의 단독 오탐 69%가 그대로 화면 등급이 됐습니다.

지금은 **결함 패턴을 게이트로, ISO를 높이로** 씁니다. 오탐이 69% → 3%로 내려가고 검출은 74% → 66%로 8%p 줍니다.

덤이 하나 있습니다 — **머신 클래스를 잘못 잡아도 오탐이 안 흔들립니다**(Class I·II·III 전부 3~4%). ISO가 경보를 켜지 않으니까요. 예전에는 클래스 하나 잘못 고르면 오탐이 49%~75%로 요동쳤습니다.

> **이 69%는 실기 설비의 오탐률이 아닙니다 — 머신 클래스 설정 문제도 아닙니다.**
> 검증 풀은 전부 **가속수명시험대**입니다. 건전한 시험대가 고하중으로 돌아 진동이 원래 높고,
> 결함 초기 베어링은 광대역 속도가 낮습니다. 그래서 **정상의 ISO 중앙값(1.33 mm/s)이
> 결함의 중앙값(1.21)보다 높습니다** — 이 풀에서 ISO 값은 손상 여부를 구분하지 못합니다.
>
> 클래스를 아무리 완화해도 안 됩니다: Class IV(2.80 mm/s, ISO 최대)에서도 정상의 36%가 존 A를 넘고,
> 오탐 3%가 되려면 경계가 5.59 mm/s — ISO 최대의 2배 — 여야 하는데 그때는 검출이 30%로 떨어집니다.
>
> ISO 10816/20816은 **정상 운전 중인 실기 설비**를 위한 규격이고 가속수명시험대는 그 대상이 아닙니다.
> 따라서 위 표가 재는 것은 **"규격 대상이 아닌 장비에 ISO 판정을 걸면 어떻게 되나"**입니다.

### 이 설계의 대가

| 잃은 것 | 크기 |
| :--- | :--- |
| 검출 8%p (74% → 66%) | 네 축이 잡던 것 중 일부를 놓칩니다 |
| **베어링 아닌 고장의 알림** | 불평형·정렬불량·풀림은 등급이 안 오릅니다 |
| **베이스라인 축의 알림** | 단독 오탐 0%·검출 28%인 가장 깨끗한 축인데 알림에서 빠졌습니다 |

세 번째는 시간축 때문입니다 — 베이스라인은 10초 축인데 등급은 10분 축이라, 같은 이벤트 흐름에 섞으면 이벤트 시각의 뜻이 흐려집니다. **값은 근거표에 그대로 남고 알림만 안 갑니다.**

## 시간축 성적 — NASA IMS 무알림 병행운전

전 수명 시험을 **실제 감시 주기(10분)로** 되돌려, 알림을 끄고 판정만 돌린 결과입니다.
끝까지 건전했던 베어링이 같은 시험대에 함께 돌아 오경보의 분모가 제대로 잡힙니다.

> **주기를 성글게 잡으면 오경보가 통째로 사라져 보입니다.** 처음에는 3시간 간격으로 돌려
> 측정점·월당 0.92건이라는 값을 얻었는데, 판정 횟수가 실제의 1/18이라 흩어진 오탐을 대부분
> 건너뛴 것이었습니다. 같은 태그·같은 기간을 10분으로 다시 돌리니 **13배**가 나왔습니다.
> 아래 숫자는 전부 10분 주기 값입니다.

### 확정 규칙 — 두 회차 연속

등급은 **같은 판정이 두 회차 연속**이라야 확정됩니다. 시간이 아니라 회차로 세는 이유는
판정이 추출 주기(기본 10분)로 돌기 때문입니다 — 분 단위 설정은 전부 "다음 회차"가 되어 뜻이 없었습니다.

**결함 셋 모두 "첫 단발 → 긴 공백 → 연속 구간" 모양이었습니다.**

| 베어링 | 첫 단발 | 그 뒤 | 연속 시작 |
| :--- | :--- | :--- | :--- |
| Set 2 B1 (외륜) | 1.11일차 | **2.6일 공백** | **3.70일차** |
| Set 1 B4 (구름체) | 0.10일차 | **7일 공백** | **9.8일차** |
| Set 1 B3 (내륜) | 33.3일차 | — | 없음 |

첫 단발에 현장을 가면 아무것도 못 찾습니다. 같은 성질의 단발이 **건전 베어링 7대에서 77번** 났고,
운영자는 둘을 구분할 방법이 없습니다.

### 결함 베어링 — 확정 시점

| 베어링 | 부위 | 첫 경보 | 시험 기간 |
| :--- | :--- | :--- | :--- |
| Set 2 B1 | 외륜 | **잔여 46% = 약 3.1일** | 6.8일 |
| Set 1 B4 | 구름체 | **잔여 72% = 약 25일** (부위는 못 말함) | 34.5일 |
| Set 1 B3 | **내륜** | **미검출** (말기 단발 2회뿐) | 34.5일 |

**2/3 검출.** 단발까지 받으면 3/3이 되지만, 그때 얻는 "더 이른" 경보는 위 표의 첫 단발이라
현장에서 확인할 것이 없습니다. 내륜은 33.3일차·34.1일차에 단발 두 번이 전부라 예방정비에 쓸 수 없습니다.

### 건전 베어링의 오경보 — 확정 규칙별

건전 7측정점 · 158일(Set 1 · Set 2) 실측입니다.

| 확정 규칙 | 오경보 | 측정점·월당 | 결함 검출 |
| :--- | ---: | ---: | ---: |
| 단발도 확정 | 77건 | **14.6건** | 3/3 (전부 단발) |
| **두 회차 연속** | **28건** | **5.3건** | **2/3** |
| 세 회차 연속 | 19건 | 3.0건 | 2/3 |

분모는 **측정점**입니다 — 한 베어링에 채널이 둘이면 알람도 둘에서 따로 나오므로, 운영자가 실제로 받는 양은 측정점 기준입니다.

세트별 편차가 큽니다. **Set 1(건전 4점 · 138일)은 두 회차 기준으로 월 1.1건**이고,
Set 2는 34건입니다 — Set 2는 옆 베어링이 파손 중인 최악 조건이라 축을 타고 실렸을 가능성이 큽니다.
정상 환경은 Set 1에 가깝습니다.

**확정에 못 간 단발도 버리지 않습니다.** `관찰` 이벤트로 이력에 남고, 매 회차 격자 점수가
시계열로 따로 쌓여 추세 차트에 그려집니다 — 알림만 나가지 않습니다.

> **가속수명시험의 %를 실기 설비 시간으로 옮기지 마십시오.** 고하중 가속시험은 개시 구간보다
> 진전 구간을 훨씬 크게 압축합니다. **실기 설비의 리드타임·오경보 검증 근거는 아직 없습니다.**

### 임계값의 안정성 (LODO)

감시 채택 임계 3.0이 특정 데이터셋에 맞춰진 값인지 확인했습니다. 데이터셋 하나씩 빼고 나머지로 임계를 고른 뒤, 빼놓은 셋에서 오탐을 잽니다.

| 뺀 셋 | 고른 임계 | 그 셋의 오탐 |
| :--- | ---: | ---: |
| CWRU · MFPT · Paderborn · Paderborn(900rpm) | **3.05** (네 폴드 전부 일치) | **0/55** |
| XJTU | 2.43 | 13/45 |

전체 풀에서 고른 값(3.03)과 다섯 폴드 중 넷이 일치하므로 **임계는 안정적입니다.**

XJTU 한 폴드만 다른 이유는 그 셋의 "정상" 라벨입니다 — 12 kN 하중으로 파괴될 베어링의 **초기 구간**을 정상으로 씁니다. 그 셋을 빼고 학습하면 임계가 2.43으로 내려가고 거기에 걸립니다. 임계 과적합이 아니라 라벨 문제입니다.

## 못 하는 것 — 이름으로 적습니다

| | 왜 |
| :--- | :--- |
| **내륜 조기 검출** | 34.5일 시험에서도 미검출. 변조로 에너지가 `BPFI ± k·1×`로 퍼져 지배 피크가 안 섭니다 |
| **구름체 부위 특정** | `BPFO = n × FTF`가 **정확한 항등식**이라 구름체 격자가 외륜과 겹칩니다. 검출은 되지만 "부위 미상"으로 나갑니다 |
| **케이지 결함** | 결함주파수로 원리적 불가. 파단은 분 단위로 진행해 예고가 없습니다 |
| **불평형 · 정렬불량 · 풀림** | 위상(타코)·축방향 채널이 없으면 **원리적으로** 판별 불가. 진폭이 높다는 사실만 표시하고 등급은 안 올립니다 |
| **왜 상했나 (고장 모드)** | 피로·윤활불량·전식·마모는 판정하지 않습니다. 부위 + 운전 이력으로 사람이 좁힙니다 |
| **열화 1단계** | AE 대역(20~60 kHz)은 샘플링이 안 닿습니다 |
| **초 단위 사고** | 판정이 10분 주기입니다. 순간 파단·이물 유입은 보호계전기·인터록의 영역입니다 |
| **대형 · 저속 · 가변속 설비** | 검증 풀에 없습니다 (아래 참고) |

> **대형 설비에서 복조 대역이 맞는지는 아직 모릅니다.**
> 복조 대역은 1~5 kHz 고정입니다. 이 대역에 실제로 자주 걸리는 것은 **가속도계 마운팅 공진**
> (부착 방식에 따라 수 kHz)이고, 베어링 링 자체의 굴곡 모드는 설비가 커질수록 **낮아집니다.**
> 그래서 "대형 설비는 공진이 더 높아서 놓친다"는 설명은 물리적으로 맞지 않습니다.
> 검증 풀에 대형 설비가 없으므로 **어느 방향으로 틀리는지 측정된 바가 없습니다.**

## 표본의 한계

- **시간축은 베어링 14개(NASA IMS)의 사례 연구입니다.** 백분율만 인용하지 말고 원표를 함께 보십시오
- **가속수명시험 편향** — Paderborn에서 인공 가공 결함이 실제 가속수명 손상보다 뚜렷하게 잘 잡혔습니다.
  같은 방향의 편향이 리드타임에도 있을 수 있습니다
- 검증 풀에 **대형·저속·가변속 설비가 없습니다**
- **실기 설비에서 측정된 적이 없습니다.** 위 5.3건은 시험대 값입니다 — 알림을 켜기 전에 대상 설비에서 무알림 병행운전으로 직접 재십시오

## 시도했다가 물린 것

같은 오탐률에 고정하고 비교한 결과입니다. **다시 시도하기 전에 이 표를 보십시오.**

> 아래 검출률은 시도 당시의 검증 풀·설정에서 잰 상대 비교값입니다. 현재 성적(66%)과 직접 비교하지 말고, **같은 줄의 "현행"과만** 비교하십시오.

| 시도 | 검출 | 왜 실패했나 |
| :--- | :--- | :--- |
| 당시 현행 | **54%** | — |
| 커토그램으로 복조 대역 선택 | 6~11% | 첨도 최대화가 안티에일리어싱 잡음·인버터 스위칭 대역에 붙잡힙니다. **첨도를 해석 신호에 거는 정식 SK로 고쳐도 마찬가지**였습니다 — real 6% · `\|z\|` 6% · 복소 SK 7%, 셋 다 12~16 kHz대를 고릅니다. 구현 결함이 아니라 목적함수의 문제입니다 |
| 실측 1× 기준 결함주파수 | 31% | 실측 흔들림이 BPFI(≈9×)에서 9배 증폭. 명판은 틀려도 일관되게 틀립니다 |
| 켑스트럼 프리화이트닝 | 29% | 대역통과가 이미 축 성분을 걸러서, 남은 1×는 이산 성분이 아니라 **변조**입니다 |
| 포락선 정수 차수 억제 | 45~48% | 16볼 BPFO가 7.09×라 정수와 1.3% 차이 — 축 계열을 지우면 근거도 지워집니다 |
| 두 대역 하이브리드 | 동률 | Šidák 보정하면 이득이 사라집니다 — 저역만으로 충분합니다 |
| 롤업 RMS로 판정 앵커 지명 | 72% | 결함 근거는 진해지지만 건전 설비의 최대 순간 전이도 같이 찾습니다. 같은 오탐률에서 균등 배치가 89%로 이깁니다 |
| 국소 잡음층 정규화 | 50% | 표적 주변 ±64빈 중앙값으로 나누면 **강한 결함일수록 측대역이 잡음층을 부풀려** 자기 근거를 스스로 깎습니다 |
| Stouffer z 결합 | 52% | 무정보 자리를 중립으로 만들면 내륜이 유리해질 것 같지만 검출·내륜 모두 안 올랐습니다 |
| 제곱 포락선(SES) | 52% | 곱 성분이 갈려 선명해질 것 같지만 실제로는 **없는 하모닉을 만듭니다** — AM 합성에서 2차/1차 = 0.15 |
| 앵커 지속성 요건(K곳 이상) | 56~72% | 오탐은 눌리지만 **단발로 서는 진짜 결함이 같이 죽습니다** |
| 저역 경계를 200 Hz로 낮춤 | 하락 | 축 회전 성분과 그 변조가 대역 안으로 들어와 격자에 우연히 맞습니다 |
| **네 축 최댓값 (예전 방식)** | **74% / 오탐 69%** | 축이 늘면 등급은 올라가기만 하므로 ISO 축의 오탐이 그대로 화면에 나옵니다 |
| **학습 축을 게이트에 포함** | 오탐 3% → 15% | **같은 태그가 학습 여부에 따라 다른 등급**을 냅니다 — 일회성 분석이 학습 상태에 매이면 안 됩니다 |
| 감시 창 50회전 | 검출 동일(59%) | 25회전과 검출이 같은데 계산 비용만 2배입니다 |
