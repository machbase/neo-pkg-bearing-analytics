# 이 도구가 하는 일과 하지 않는 일

[English](./scope.en.md) | [한국어](./scope.kr.md) | [日本語](./scope.ja.md)

> **사람의 진단을 대체하지 않습니다.**
> 진단과 진단 사이의 공백을 메우고, 점검 순서를 매기고, 점검자가 볼 스펙트럼을 미리 띄워 둡니다.

ISO 18436 자격 체계로 경계를 그으면 이렇습니다 — **Category I(선별·데이터 수집)을 자동화하고,
Category II(고장 진단)의 진입 근거를 인쇄합니다. 확정은 사람이 합니다.**

아래 숫자는 전부 공개 데이터셋 실측입니다. 검출률은 **오탐률·모집단과 짝으로만** 적습니다 —
그 셋 중 하나라도 빠진 숫자는 비교가 불가능합니다.

---

## 무엇을 재는 도구인가

**베어링 진단 도구입니다.** 등급은 베어링 결함주파수 자리에 근거가 설 때만 오릅니다.

진동이 높다는 사실만으로는 등급이 오르지 않습니다 — 그건 화면에 따로 적힙니다. 불평형·정렬불량·풀림처럼 베어링이 아닌 원인은 **판정하지 않고**, 위상(타코)·축방향 채널 없이는 원리적으로 판별할 수 없기 때문에 앞으로도 판정하지 않습니다.

이 선택의 근거는 아래 [축을 합치면 어떻게 되는가](#축을-합치면-어떻게-되는가)에 있습니다.

## 두 가지 모드

| | 묻는 것 | 창 | 언제 |
| :--- | :--- | :--- | :--- |
| **상세분석** (일회성) | "이 신호가 무엇처럼 보이나" | 100회전 이상(최대 22초) | 사람이 기간을 고를 때 |
| **상시감시** | "이 설비가 나빠지고 있나" | 25회전 | 추출 주기마다(기본 10분) |

**두 모드 모두 학습이 필요 없습니다.** 등급을 만드는 두 축(결함 패턴·ISO 존)이 절대 기준이기 때문입니다. 베이스라인·대역은 학습이 필요하지만 **등급도 알림도 만들지 않고 근거로만** 쓰입니다.

**리드타임 숫자는 상시감시에서만 나옵니다.** 일회성 분석에는 시간 흐름이 없습니다.

> 학습 기간에 **결함이 이미 진행 중이면 그 결함이 정상 기준이 됩니다.** 자동 필터가 걸러 주지 못하는 부분이라, 학습 구간은 정비 이력과 대조해 사람이 골라야 합니다. 다만 학습 축은 등급을 만들지 않으므로, 학습이 틀려도 **오경보로 이어지지는 않습니다** — 근거 표시만 틀립니다.

## 스냅샷 성적 — 383건, 공개셋 4종

CWRU · MFPT · Paderborn · XJTU-SY. 기하(볼수·볼경·피치경·접촉각)가 1차 출처에
공개된 것만 골랐습니다.

| | 결과 |
| :--- | :--- |
| **정상 오탐** | **3/100 (3%)** |
| **결함 검출** | **183/283 (65%)** |
| 결함 전체 중 부위까지 맞힘 | 153/283 (약 54%) |
| 검출된 것 중 부위 적중 | 153/169 (91%) |

검출은 등급이 켜진 건(결함 패턴 채택)만 셉니다. 부위 적중의 분모 169는 검출 183건 중 결함이 한 종류인 케이스이며(외륜·내륜이 함께 상한 복합 결함 14건은 어느 부위를 말해도 맞게 되어 제외), 이 중 4건은 구름체 후보라 부위 미상으로 나갑니다.

**"검출된 것 중 91%"를 단독으로 인용하면 안 됩니다** — 판정이 보수적일수록 좋아지는 조건부 값입니다.
사용자에게 실제로 남는 것은 **결함 둘 중 하나 남짓에서 부위까지 맞히는 정도**입니다.

부위별로는 **외륜이 가장 잘 서고, 내륜이 중간, 구름체는 부위를 말하지 않습니다.**

> **스냅샷과 시간축이 다르게 답하는 항목이 있습니다.** 구름체는 스냅샷 한 장에서는 사실상 못 잡지만,
> 전 수명 시험에서는 **잔여 72%(약 25일) 남기고 잡혔습니다**(NASA IMS Set 1 B4).
> 묻는 것이 다르기 때문입니다 — "이 한 장에서 구름체라고 **이름 붙일 수 있나**"는 기하가 겹쳐 안 되고,
> "이 베어링이 **나빠지고 있나**"는 됩니다. 부위를 못 말해도 이상은 섭니다.

### 축을 합치면 어떻게 되는가

같은 383건에서 축별로 갈라 재면 이렇습니다.

| 축 | 단독 오탐 | 단독 검출 |
| :--- | :--- | :--- |
| **결함 패턴** | **3/100 (3%)** | 183/283 (65%) |
| **베이스라인** | **0/100 (0%)** | 79/283 (28%) |
| 대역 | 13/100 (13%) | 117/283 (41%) |
| **ISO 존** | **69/100 (69%)** | 104/283 (37%) |
| **네 축 중 하나라도 켜지면 경보** | **69/100 (69%)** | 209/283 (74%) |
| **현행 — 패턴이 게이트, ISO가 높이** | **3/100 (3%)** | **183/283 (65%)** |

네 축의 최댓값을 등급으로 쓰면 축이 늘수록 등급은 올라가기만 하므로, ISO 축의 단독 오탐 69%가 그대로 화면 등급이 됩니다.

그래서 **결함 패턴을 게이트로, ISO를 높이로** 씁니다. 오탐이 69% → 3%로 내려가고 검출은 74% → 65%로 9%p 줍니다. 등급은 결함 패턴이 켤 때만 오르므로 검출은 결함 패턴 단독과 같습니다.

덤이 하나 있습니다 — **머신 클래스를 잘못 잡아도 오탐이 거의 흔들리지 않습니다**(Class I·II·III 전부 3\~4%). ISO가 경보를 켜지 않으니까요.

> **이 69%는 실기 설비의 오탐률이 아닙니다 — 머신 클래스 설정 문제도 아닙니다.**
> 검증 풀은 전부 **가속수명시험대**입니다. 건전한 시험대가 고하중으로 돌아 진동이 원래 높고,
> 결함 초기 베어링은 광대역 진동이 낮습니다. 그래서 이 풀에서는 정상과 결함의 ISO 값이 거의 같거나
> 오히려 정상이 높아, ISO 값이 손상 여부를 구분하지 못합니다. 클래스를 완화해도 해결되지 않습니다.
>
> ISO 10816/20816은 **정상 운전 중인 실기 설비**를 위한 규격이고 가속수명시험대는 그 대상이 아닙니다.
> 따라서 위 표가 재는 것은 "**규격 대상이 아닌 장비에 ISO 판정을 걸면 어떻게 되나**"입니다.

### 이 설계의 대가

| 잃은 것 | 크기 |
| :--- | :--- |
| 검출 9%p (74% → 65%) | 네 축이 잡던 것 중 일부를 놓칩니다 |
| **베어링 아닌 고장의 알림** | 불평형·정렬불량·풀림은 등급이 안 오릅니다 |
| **베이스라인 축의 알림** | 단독 오탐 0%·검출 28%인 가장 깨끗한 축인데 알림에서 빠졌습니다 |

세 번째는 시간축 때문입니다 — 베이스라인은 빠른 축(판정 주기)인데 등급은 느린 축(추출 주기)이라, 같은 이벤트 흐름에 섞으면 이벤트 시각의 뜻이 흐려집니다. **값은 근거표에 그대로 남고 알림만 안 갑니다.**

## 시간축 성적 — 전 수명 시험

NASA IMS 전 수명 시험을 **실제 감시 주기(10분)로** 되돌려, 알림을 끄고 판정만 돌린 결과입니다.
끝까지 건전했던 베어링이 같은 시험대에 함께 돌아 오경보의 분모가 제대로 잡힙니다.

### 결함 베어링 — 확정 시점

| 베어링 | 부위 | 첫 경보(두 회차 연속 확정) | 시험 기간 |
| :--- | :--- | :--- | :--- |
| Set 2 B1 | 외륜 | **잔여 46% = 약 3.1일** | 6.8일 |
| Set 1 B4 | 구름체 | **잔여 72% = 약 25일** (부위는 못 말함) | 34.5일 |
| Set 1 B3 | **내륜** | **미검출** (말기 단발 2회뿐) | 34.5일 |

**2/3 검출.** 결함 셋 모두 **"첫 단발 → 긴 공백 → 연속 구간"** 모양이었습니다. 단발까지 받으면 3/3이 되지만, 그때 얻는 "더 이른" 경보는 첫 단발이라 현장에서 확인할 것이 없습니다. 내륜은 시험 말기에 단발 두 번이 전부라 예방정비에 쓸 수 없습니다.

### 건전 베어링의 오경보 — 확정 규칙별

건전 7측정점 · 158일 실측입니다.

| 확정 규칙 | 측정점·월당 오경보 | 결함 검출 |
| :--- | ---: | ---: |
| 단발도 확정 | **14.6건** | 3/3 (전부 단발) |
| **두 회차 연속 (현행)** | **5.3건** | **2/3** |
| 세 회차 연속 | 3.0건 | 2/3 |

분모는 **측정점**입니다 — 한 베어링에 채널이 둘이면 알람도 둘에서 따로 나오므로, 운영자가 실제로 받는 양은 측정점 기준입니다.

시험 세트별 편차가 큽니다. 옆 베어링이 파손 중인 최악 조건(Set 2)에서 오경보가 몰렸고, 그렇지 않은 세트(Set 1)는 두 회차 기준으로 **측정점·월당 1.1건**이었습니다. 정상 환경은 Set 1에 가깝습니다.

**확정에 못 간 단발도 버리지 않습니다.** `관찰` 이벤트로 이력에 남습니다 — 알림만 나가지 않습니다.

> **가속수명시험의 %를 실기 설비 시간으로 옮기지 마십시오.** 고하중 가속시험은 개시 구간보다
> 진전 구간을 훨씬 크게 압축합니다. **실기 설비의 리드타임·오경보 검증 근거는 아직 없습니다.**

## 못 하는 것 — 이름으로 적습니다

| | 왜 |
| :--- | :--- |
| **내륜 조기 검출** | 34.5일 시험에서도 미검출. 변조로 에너지가 `BPFI ± k·1×`로 퍼져 지배 피크가 안 섭니다 |
| **구름체 부위 특정** | 구름체 결함주파수 격자가 외륜 격자와 겹칩니다. 검출은 되지만 "부위 미상"으로 나갑니다 |
| **케이지 결함** | 결함주파수로 원리적 불가. 파단은 분 단위로 진행해 예고가 없습니다 |
| **불평형 · 정렬불량 · 풀림** | 위상(타코)·축방향 채널이 없으면 **원리적으로** 판별 불가. 진폭이 높다는 사실만 표시하고 등급은 안 올립니다 |
| **왜 상했나 (고장 모드)** | 피로·윤활불량·전식·마모는 판정하지 않습니다. 부위 + 운전 이력으로 사람이 좁힙니다 |
| **열화 1단계** | AE 대역(20\~60 kHz)은 샘플링이 안 닿습니다 |
| **초 단위 사고** | 등급 판정이 추출 주기(기본 10분)마다입니다. 순간 파단·이물 유입은 보호계전기·인터록의 영역입니다 |
| **대형 · 저속 · 가변속 설비** | 검증 풀에 없습니다 (아래 참고) |

> **대형 설비에서 복조 대역이 맞는지는 아직 모릅니다.**
> 등급을 정하는 결함 패턴의 복조 대역은 1\~5 kHz 고정입니다. 이 대역에 실제로 자주 걸리는 것은 **가속도계 마운팅 공진**
> (부착 방식에 따라 수 kHz)이고, 베어링 링 자체의 굴곡 모드는 설비가 커질수록 **낮아집니다.**
> 그래서 "대형 설비는 공진이 더 높아서 놓친다"는 설명은 물리적으로 맞지 않습니다.
> 검증 풀에 대형 설비가 없으므로 **어느 방향으로 틀리는지 측정된 바가 없습니다.**

## 표본의 한계

- **시간축은 NASA IMS 베어링 채널 14개의 사례 연구입니다.** 백분율만 인용하지 말고 원표를 함께 보십시오
- **가속수명시험 편향** — Paderborn에서 인공 가공 결함이 실제 가속수명 손상보다 뚜렷하게 잘 잡혔습니다.
  같은 방향의 편향이 리드타임에도 있을 수 있습니다
- 검증 풀에 **대형·저속·가변속 설비가 없습니다**
- **실기 설비에서 측정된 적이 없습니다.** 위 5.3건은 시험대 값입니다 — 알림을 켜기 전에 대상 설비에서 알림 없이 판정만 돌려(병행운전) 직접 재십시오
