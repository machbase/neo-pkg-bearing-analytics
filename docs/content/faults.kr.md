#

이 문서는 앱이 **어떤 고장을 어떤 근거로 구분하는지**, 그리고 **그 구분에 무엇이 필요한지**를 정리합니다.

핵심 원칙 하나가 문서 전체를 관통합니다:

> **설비 설정이 분석 방향을 정합니다.** 베어링 품번을 모르면 결함주파수를 대조할 수 없고, 마운팅을 모르면 어느 고주파까지 믿을 수 있는지 알 수 없습니다. 앱은 그럴 때 점수를 0으로 주는 대신 **"측정 불가"** 로 표시합니다 — 볼 수 없는 것과 가능성이 낮은 것은 다르기 때문입니다.

## 학습은 분석의 전제가 아닙니다

판정 축은 넷인데 역할이 둘로 갈립니다.

| | 축 | 학습 | 하는 일 |
| :--- | :--- | :--- | :--- |
| **등급을 만드는 축** | 결함 패턴 · ISO 존 | **불필요** | 등급과 알림. 상세분석·리포트도 이 둘만으로 완결됩니다 |
| **근거 축** | 베이스라인 · 대역 | 필요 | "평소 대비" 근거 표시. 등급과 알림은 만들지 않습니다 |

일회성 분석에는 "평소"가 없습니다. 그래서 학습이 안 된 설비에서도 상세분석과 리포트는 그대로 나오고, 학습된 축이 있으면 **근거가 한 층 더 보일 뿐** 등급은 바뀌지 않습니다.

## 두 갈래로 나눠 봅니다

| | 묻는 것 | 계열 | 조치 |
| :--- | :--- | :--- | :--- |
| **진동 축** | 이 지점 진동이 커졌나 | 서브동기 · 1× 대역 · 결함 대역 · 고주파 · 1\~2 · 2\~4 · 4\~8 · 8 kHz+ | 밸런싱 · 정렬 · 체결 (시간 단위) |
| **베어링 축** | 이 베어링이 상했나 | 포락선 주기성 · BPFO · BPFI · BSF | 부품 조달 · 분해 (주 단위) |

**둘을 한 덩어리로 두면 안 됩니다.** 옆 베어링의 결함이 축을 타고 전달되면, 멀쩡한 베어링에 붙은 센서의 고주파 대역이 결함 베어링보다 더 높게 나오기도 합니다. "진동이 크다"는 맞지만 "그 베어링이 상했다"는 아닙니다. 포락선 결함주파수만 보면 둘이 갈립니다.

## 회전체 계통 — 진동 축

### 불평형 (Imbalance)
회전체 질량이 편심된 상태입니다.

- **시그니처** — 1× 동기 성분이 지배. 하모닉이 적음
- **확정 조건** — **위상과 축방향 측정이 있어야** 정렬불량과 구분됩니다. 단일 채널로는 원리적으로 판별 불가라 앱이 "측정 불가"로 표시합니다
- **조치** — 현장 동적 밸런싱

### 정렬 불량 (Misalignment)
커플링으로 이어진 두 축의 중심이 어긋난 상태입니다.

- **시그니처** — 2× 성분이 우세. 축방향 진동 동반
- **확정 조건** — 불평형과 같습니다(위상·축방향 필요)
- **조치** — 레이저 얼라인먼트

### 기계적 풀림 (Looseness)
체결·고정·하우징이 헐거운 상태입니다.

- **시그니처** — **1×의 정수배 하모닉이 여러 개**(3개 이상). 지배 성분이 동기
- **조치** — 체결·고정·베어링 하우징 점검

## 베어링 계통 — 베어링 축

결함 주파수는 회전수와 베어링 기하로 정해집니다. **품번(또는 형상)을 넣어야** 대조가 가능합니다.

| 신호 | 어디가 상했나 | 계산식 (× 회전수) |
| :--- | :--- | :--- |
| **BPFO** | 바깥 궤도(외륜) | (n/2)(1 − (d/D)cos α) |
| **BPFI** | 안쪽 궤도(내륜) | (n/2)(1 + (d/D)cos α) |
| **BSF** | 구름체(볼·롤러) | (D/2d)(1 − ((d/D)cos α)²) |
| FTF | 케이지 | (1/2)(1 − (d/D)cos α) |

### 왜 포락선이 필요한가
결함을 지날 때마다 나는 충격은 하우징의 **수 kHz 공진을 울립니다.** 원시 스펙트럼에는 "고주파가 있다"까지만 보이고 **"몇 Hz로 두들기나"** 는 진폭 변조에 숨습니다. 포락선 복조가 그 반복 주파수를 선으로 꺼냅니다.

### 복조 대역은 1\~5 kHz 고정입니다
충격이 가장 두드러지는 대역을 자동으로 고르는 방식(커토그램)은 판정에 쓰지 않습니다. 이 방식은 결함이 아닌 신호 — 고주파 끝의 필터 잡음, 인버터가 만드는 전기 성분 — 에 쉽게 붙잡히고, 결함이 뚜렷할수록 오히려 그 대역을 피하는 성질이 있어 공개 데이터 검증에서 검출이 크게 떨어졌습니다.

그래서 등급을 정하는 결함 패턴과 상세분석의 포락선은 **복조 대역을 1\~5 kHz로 고정**했습니다. (대역 추출이 쌓는 포락선 추이는 마운팅 상한·샘플링 한계 아래의 가장 높은 옥타브를 씁니다.) 커토그램은 계속 계산해 상세분석의 **대역별 충격성** 차트에 띄웁니다 — 어느 대역이 충격적인지는 그 자체로 진단 정보이기 때문입니다. 다만 **판정에는 쓰지 않습니다.**

샘플링이 낮아 1\~5 kHz가 성립하지 않으면(5 kHz가 측정 가능한 최대 주파수의 95% 안에 들지 않으면 — 샘플레이트 약 10.5 kHz 미만) **전대역으로 복조합니다.** 이때는 근거가 약하고 조기 베어링 결함은 잡히지 않습니다.

> **대형 설비에서 이 대역이 맞는지는 모릅니다.** 검증 데이터에 대형 설비가 없습니다.
> 1\~5 kHz에 실제로 자주 걸리는 것은 **가속도계 마운팅 공진**(부착 방식에 따라 수 kHz)이고,
> 베어링 링 자체의 굴곡 모드는 설비가 커질수록 **낮아집니다.** 그래서 "대형 설비는 공진이
> 더 높아서 놓친다"는 설명은 물리적으로 맞지 않습니다 — **어느 방향으로 틀리는지 측정된 바가 없습니다.**

### FTF는 결함 근거가 아닙니다
**케이지는 정상 베어링에서도 항상 돕니다.** 멀쩡한 채널에서도 케이지 회전 성분이 처음부터 계속 보이므로, 관측 사실로만 기록하고 점수에는 넣지 않습니다.

### 오일 훨 (Oil whirl)
유막(저널) 베어링에서 축이 유막 위를 떠도는 현상입니다.

- **시그니처** — 0.38\~0.48× 비동기 성분 지배
- **중요** — **구름베어링으로 형식이 지정되면 후보에서 내립니다.** 유막 베어링에서만 생기는 현상이라 물리적으로 성립하지 않습니다. 형식 미지정이면 알 수 없으므로 그대로 둡니다

### 케이지 결함 (FTF 추정)
- **시그니처** — 0.35\~0.45× 지배. 품번을 몰라도 이 구간 판정은 가능합니다(구름베어링의 d/D가 대부분 0.15\~0.25라 FTF가 그 범위에 갇힘)
- **주의** — 위 "FTF는 결함 근거가 아니다"와 별개 항목입니다. 이쪽은 **원시 스펙트럼의 지배 차수**를 보고, 저쪽은 포락선 결함주파수 대조입니다

## 구동·부하 계통

### 벨트·풀리 (Belt)
- **시그니처** — 벨트 통과주파수와 그 하모닉
- **필요 설정** — 구동방식 **벨트**, 풀리 **피치 지름** 2개(D1 구동·D2 종동) + 벨트 길이. 길이가 없으면 벨트 통과주파수 대조가 불가합니다
- 풀리비만 알아도 반대쪽 축의 1×가 대조되어, 정체 모를 비동기 성분의 **귀속**이 닫힙니다
- **센서가 벨트 반대편(팬·펌프 등)에 붙어 있으면** 센서 위치를 **종동측**으로 고르십시오. 그러면 결함 패턴·결함주파수·대역이 **종동축 회전수**로 계산됩니다. 잰 종동축 회전수를 넣으면 그 값을, 비워 두면 RPM × D1 ÷ D2를 씁니다. 종동측인데 회전수를 알 수 없으면 그 태그는 결함 패턴을 재지 않습니다 — 모터 회전수로 대조하면 엉뚱한 주파수가 우연히 맞기 때문입니다

> 종동축 회전수가 1\~2%만 틀려도 결함은 잡되 부위를 자주 틀립니다. 풀리 바깥지름이 아니라 피치 지름을 쓰거나, 잰 회전수를 입력하십시오.

### 베인/블레이드 통과 (Vane pass)
- **시그니처** — 날개수 × 1×
- **필요 설정** — 임펠러 날개수

### 기어 메시 (Gear mesh)
- **시그니처** — 잇수 × 1×(메시 주파수)와 **1× 간격 측대역**
- **음성 소견이 유의미한 드문 경우** — 메시는 관측되는데 측대역이 없으면 그게 **정상 기어의 모습**입니다

### 독립 회전원 (종동축·인접 기계)
- **시그니처** — **비동기** 기본파 + 그 자체 하모닉 3개 이상
- 벨트 종동축·인접 기계·기어 종동축이 대개 정체입니다. 구동 계통도 한 장이면 귀속이 닫힙니다

### 전기적 (Electrical)
- **시그니처** — 라인 주파수 관련 성분(60 Hz 계통이면 120 Hz). 회전수가 바뀌어도 움직이지 않음
- **확정** — 전원 차단 시 소멸하는지 확인해야 합니다(정지 시험)

## 설정이 무엇을 여는가

| 설정 | 없으면 |
| :--- | :--- |
| **회전수(RPM)** | 차수 해석 전부 — 모든 후보가 닫히고, 결함 패턴(등급)과 대역 추출도 멈춥니다 |
| **베어링 품번·형상** | 결함 패턴(등급) · BPFO/BPFI/BSF 대조 · 오일 훨 배제 |
| **단위** | 비우면 속도(mm/s)로 간주 — 가속도·변위 센서는 ISO 환산이 틀어져 등급 높이가 틀림 |
| **Class** | 비우면 Class II 존 경계로 판정 |
| **마운팅** | 고주파 유효 상한 — 그 위 대역은 마운팅 공진일 수 있어 따로 표시하지 못함 |
| **풀리 피치 지름·벨트 길이** | 벨트 통과주파수 · 종동축 1× |
| **센서 위치(벨트)·종동축 회전수** | 종동측 센서의 결함주파수가 모터 회전수로 계산돼 엇나감 |
| **날개수 / 기어 구동** | 베인 통과 / 메시 주파수 |

## 지금 어디까지 되는가

공개 데이터셋 4종(CWRU · MFPT · Paderborn · XJTU-SY) 383건으로 검증한 결과를 요약하면 이렇습니다.

| | 결과 |
| :--- | :--- |
| 정상 오탐 | 100건 중 3건 (3%) |
| 결함 검출 | 283건 중 183건 (65%) |
| 결함 전체 중 부위까지 맞힘 | 283건 중 153건 (약 54%) |

검출한 것만 놓고 보면 부위 적중률이 훨씬 높아 보이지만, 그 값은 판정을 보수적으로 할수록 좋아지는 조건부 값이라 단독으로 보면 안 됩니다. 손에 남는 것은 **결함 둘 중 하나 남짓에서 부위까지 맞히는 정도**입니다. 자세한 표는 [이 도구가 하는 일과 하지 않는 일]({{< relref "scope" >}})에 있습니다.

### 부위별 — 외륜만 잘 됩니다

| | 결함이 하중대에 | 신호 | 성적 |
| :--- | :--- | :--- | :--- |
| **외륜** | **고정** | 충격 크기가 일정 → 피크가 선다 | 가장 좋음 |
| 내륜 | 축과 함께 드나듦 | `BPFI ± k·1×` 측대역으로 분산 | 중간 |
| 구름체 | 케이지와 함께 드나듦 | `BSF ± k·FTF` 측대역으로 분산 | **부위 단정 불가** |

구름체는 검출은 되지만 **부위를 단정하지 않습니다.** 검증에서 구름체라고 이름 붙인 판정이 거의 맞지 않았고, 반대로 내륜·외륜 결함이 구름체로 잘못 가기도 했습니다. 물리적으로도 결함 구름체는 레이스를 함께 상하게 하므로 "부위 미상"이 정직합니다.

### 시간축에서 보면 — 외륜은 미리, 내륜은 늦게

전 수명 시험 데이터로 "고장까지 얼마나 남기고 첫 경보를 냈나"를 재 보면, **외륜은 정비 계획을 세울 시간을 주지만, 내륜은 "곧 선다"는 통보에 가깝습니다.** 숫자는 [이 도구가 하는 일과 하지 않는 일 › 시간축 성적]({{< relref "scope#시간축-성적--전-수명-시험" >}})에 있습니다.

### 종류를 단정하지 않는 경우
대역 추출이 쌓는 포락선 결함주파수 계열(BPFO·BPFI·BSF)이 함께 올라 1·2순위가 근접하면 **후보를 나열하고 "구분 불충분"** 이라고 적습니다. 등급을 정하는 결함 패턴은 가장 강한 후보 하나를 고릅니다.

**어느 쪽이든 베어링 교체이므로 정비 계획은 탐지만으로 섭니다.** 종류가 필요한 것은 **근본원인 분석**입니다 — 내륜은 과부하·정렬불량, 외륜은 하우징·전류 통과를 의심하는 식으로 재발 방지가 갈립니다.
