#

これらのドキュメントに出てくる用語を、順を追って解説します。振動分析が初めての方でも、このページさえ読めば残りのドキュメントを理解できます。

---

## 基本

### 振動センサーとRMS

設備に取り付けたセンサーは、振動を1秒間に数千\~数万回測定します。その大量の数値を1つにまとめた値が**RMS**（実効値）です。単純に平均をとると上下の振れが打ち消し合って0に近くなるため、2乗して平均した後に平方根をとります。**「今この設備がどれだけ振動しているか」を1つの数値で表したもの**と考えてください。

### 回転周波数と1×

軸が1秒間に何回転するかが**回転周波数**です。1800 RPMなら毎分1800回転、つまり毎秒30回転なので30 Hzです。

振動分析ではこの値を基準にして、**1×**（回転周波数と同じ成分）、**2×**（2倍）のように呼びます。設備ごとに回転数が異なるため、絶対周波数（Hz）よりも「回転数の何倍か」で表したほうが、設備どうしを比較できます。

> そのため、アプリは**回転数の入力を求めます**。回転数が分からなければ1×がどこか分からず、1×が分からなければほとんどの判定基準が成り立ちません。

### スペクトル

時間とともに上下する振動を、**周波数ごとの強さ**に変換して描いたグラフです。「どの周波数でどれだけ振動しているか」が見えます。

同じ大きさで振動していても、30 Hzで振動するのと150 Hzで振動するのとでは原因が異なります。その違いを見るためにスペクトルを使います。

### 高調波（整数倍成分）

1×の整数倍 — 2×、3×、4×… — が並んで立つ形です。機械的ゆるみのように1回転に何度もぶつかる故障が、このような列を作ります。

## ベアリング

### 欠陥周波数（BPFO · BPFI · BSF · FTF）

ベアリングが損傷すると、**損傷箇所を通過するたびに**衝撃が発生します。その衝撃が1秒間に何回起きるかは、ベアリングの形状（転動体の数・径・ピッチ）と回転数から計算できます。どこが損傷したかによって値が変わるため、逆に**どの周波数で衝撃が起きているかを見れば、どこが損傷したかが分かります**。

| 略語 | 正式名称 | 損傷箇所 |
| :--- | :--- | :--- |
| **BPFO** | Ball Pass Frequency, Outer race | 外側の軌道輪（外輪） |
| **BPFI** | Ball Pass Frequency, Inner race | 内側の軌道輪（内輪） |
| **BSF** | Ball Spin Frequency | 転動体（玉）そのもの |
| **FTF** | Fundamental Train Frequency | 転動体を保持する保持器 |

> そのため、アプリは**ベアリングの型番**を尋ねます。型番が分かればこの4つの値を計算して「その位置に衝撃があるか」を照合でき、分からなければ照合するためのグリッドそのものがありません。

### 包絡線（エンベロープ）復調

ベアリングの衝撃は**小さく速い**ものです。軸が回転する大きな振動に埋もれて、スペクトルではよく見えません。

包絡線復調は、信号の**外側の輪郭線だけを取り出す**処理です。速い振動そのものは捨てて、「どれくらいの頻度で叩いているか」だけを残します。すると埋もれていた衝撃の周期が現れ、上の欠陥周波数と照合できるようになります。

たとえるなら、遠くから聞こえる規則的なハンマーの音を聞き取るために、**音の高低ではなくリズムだけを数える**ようなものです。

等級を決める欠陥パターンと詳細分析の包絡線は、包絡線を取り出す前に**1\~5 kHz帯域だけを残して**使います。衝撃がハウジングの高周波共振を鳴らす帯域だからです。（帯域抽出が蓄積する包絡線の推移は、マウンティング上限・サンプリング限界より下の最も高いオクターブを使います。）

### カートグラム（帯域別衝撃性）

複数の周波数区間を走査し、**衝撃性が最も際立つ区間**を示すツールです。詳細分析の**帯域別衝撃性**チャートがこれにあたります。

このアプリでは**参考としてのみ**表示します。自動で選んだ区間が欠陥ではない信号（フィルター雑音・電気的成分）に引っ張られることが多いため、判定用の包絡線は、カートグラムが選んだ区間ではなく1\~5 kHzの固定帯域から取り出します。

### 側帯波

欠陥周波数の両側に**一定の間隔で**立つ小さなピークです。損傷箇所が回転とともに荷重を受けたり離れたりすると発生します。

側帯波が見えれば、単なる雑音ではなく**実際に回転と連動した衝撃**であることの根拠になります。

### ピッチ径・従動軸

- **ピッチ径** — ベアリングでは転動体の中心を結ぶ円の直径、ベルトプーリではベルトが巻き付く位置の直径です。プーリのピッチ径は外径より少し小さく、プーリの刻印やカタログに記載されています。
- **従動軸（従動側）** — ベルトでつながった設備で、モーターではない反対側（ファン・ポンプなど）の軸です。センサーがこちらのベアリングに付いている場合は、設定でセンサー位置を**従動側**に選んではじめて、欠陥周波数がその軸の回転数で計算されます。

## 信号の性質

### 尖度（Kurtosis）

振動が**どれだけ尖っているか**を測る値です。穏やかに揺れる信号は低く、ときどき大きく叩く信号は高くなります。ベアリングの初期欠陥は「普段は静かだが、ときどき叩く」形なので、尖度が先に上がります。

### クレストファクタ（Crest factor）

最大の瞬時値をRMSで割った値です。尖度と同様に**衝撃性**を見ます。

> ただし、この2つは**センサーへの打撃やケーブルの接触不良といった計測上のトラブルでも跳ね上がります**。そのため、アプリはこの値が極端に大きい場合、欠陥ではなく計測異常をまず疑います。

### 計測異常

クリッピング（飽和）・フラットライン（値がほとんど変わらない）・DCドリフト（平均値が揺れる）・単発スパイクのように、**測定そのものを信頼しにくい状態**です。このとき詳細分析は「信号異常 — センサー点検が必要」（신호 이상 — 센서 점검 필요）という警告とともに**診断保留**となります。監視では、クリッピング・フラットライン・DCドリフト・サンプル不足のときにその設備の等級判定が止まり（カード表示：判定保留 · 計測異常）、単発スパイクと極端な尖度は判定を止めずに根拠としてのみ残します。

平均値は大きいが一定しているセンサー（MEMS加速度計の重力軸など）は計測異常ではありません — 灰色の「DC成分」の案内が付くだけです。

## 判定に使う用語

### 欠陥パターン・グリッドスコア・採択ライン

**欠陥パターン**は、包絡線スペクトルでベアリングの欠陥周波数の位置（とその高調波）にエネルギーが立っているかを見る判定です。欠陥周波数の位置をまとめて**グリッド**と呼び、その位置のエネルギーが周囲の雑音の何倍かを**グリッドスコア**として算出します。グリッドスコアが**採択ライン**（監視 3.0、詳細分析 4.0）を超えると欠陥パターンが「オンになった」とみなし、**これが等級をオンにします**。

### ISO 10816ゾーン

国際規格が定める**振動の大きさの絶対基準**です。設備の種類（Class）とRMS値に応じて4つの区間に分けます。

| ゾーン | アプリ表示 | 意味 |
| :--- | :--- | :--- |
| A | 良好（양호） | 新品設備の水準 |
| B | 注意（주의） | 長期運転が可能 |
| C | 危険（위험） | 短期運転のみ、対策計画が必要 |
| D | 重大（심각） | 損傷が進行中の可能性がある |

**「どれだけ大きく振動しているか」だけを見ます** — なぜ振動しているかは教えてくれません。そのため本パッケージは、ISOゾーンを別途表示しつつ、等級は欠陥パターンがオンになったときだけ上げ、その高さをISOゾーンで決めます。

### 判定回・観察

**判定回**は、欠陥パターンを1回測定する単位です（抽出周期、既定10分）。等級は同じ判定が**2回連続**したときに確定し、アラームが出ます。最初に外れた1回は**観察**（관찰）イベントとして記録されるだけで、通知は送られません。

### 判定保留・判定不可

**判定保留**（판정 보류）は、現在その設備に等級を付けていない状態です。カードの等級の位置に表示され、理由は停止・信号途絶・計測異常・欠陥パターン測定失敗・**判定不可**などです。

**判定不可**（판정 못 함）は、RPMやベアリング形状がないため、欠陥パターンをまったく計算できない状態です。「正常」ではなく「不明」です。すべり軸受（ジャーナル軸受）もこれに該当します。

### ベースライン（平常時との比較）

同じ設備の**平常時の値**を学習しておき、そこからどれだけ外れたかを見る方式です。絶対基準（ISO）は「この程度なら大きいほう」を示し、ベースラインは「**この設備にしてはおかしい**」を示します。

ゆっくり悪化していく変化を、絶対基準を超える前に先に示します。このアプリでは等級・通知を作らず、**根拠としてのみ**表示します。その代わり、**平常時を知るには時間が必要です** — 単発の分析には使えません。

### 帯域エネルギー

スペクトルをいくつかの区間に分け、**区間ごとの強さを別々に追跡する**方式です。全体のRMS 1つだけを見ても、どの区間が大きくなったのかは分かりませんが、帯域に分けると「高周波だけが上がった」といった変化が見えます。このアプリではベースラインと同様に、**根拠としてのみ**使います。

### 測定不可

アプリが**スコアを0にせず、空欄のままにする**状態です。ベアリングの型番がなく欠陥周波数を照合できないときや、回転数がなく1×の基準を立てられないときがこれにあたります。

> **「見えないこと」と「可能性が低いこと」は違います**。0点で埋めると、情報がないのに安全そうに見えてしまうため、アプリは空欄のままにして、何を入力すべきかを知らせます。

### 判定フィンガープリント

レポートごとに残る短い文字列で、判定エンジンのルールと固定定数から計算されます。2つのレポートのフィンガープリントが同じなら、同じエンジンで判定したということです。異なれば、その間にパッケージ（判定エンジン）が変わったということです。ユーザーが変更したしきい値は、フィンガープリントではなくレポートのThresholds欄で比較します。
