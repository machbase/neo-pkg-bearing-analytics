#

> **人による診断を代替するものではありません**。
> 診断と診断の間の空白を埋め、点検の優先順位を付け、点検者が見るべきスペクトルをあらかじめ画面に表示しておきます。

ISO 18436の資格体系で線を引くと、次のようになります — **Category I（スクリーニング・データ収集）を自動化し、
Category II（故障診断）に進むための根拠を出力します。確定は人が行います**。

以下の数値はすべて公開データセットでの実測です。検出率は**誤検知率・母集団と必ず対にして**記載します —
この3つのうち1つでも欠けた数値は、比較することができません。

---

## 何を測るツールか

**ベアリング診断ツールです**。等級は、ベアリングの欠陥周波数の位置に根拠が立ったときだけ上がります。

振動が高いという事実だけでは等級は上がりません — それは画面に別途表示されます。アンバランス・ミスアライメント・ゆるみのようなベアリング以外の原因は**判定せず**、位相（タコ信号）・軸方向チャンネルなしでは原理的に判別できないため、今後も判定しません。

この選択の根拠は、下の[軸を組み合わせるとどうなるか](#軸を組み合わせるとどうなるか)にあります。

---

## 2つのモード

| | 問うこと | ウィンドウ | タイミング |
| :--- | :--- | :--- | :--- |
| **詳細分析**（単発） | 「この信号は何のように見えるか」 | 100回転以上（最大22秒） | 人が期間を選んだとき |
| **常時監視** | 「この設備は悪化しているか」 | 25回転 | 抽出周期ごと（既定10分） |

**どちらのモードも学習は不要です**。等級を決める2つの軸（欠陥パターン・ISOゾーン）が絶対基準だからです。ベースライン・帯域は学習が必要ですが、**等級も通知も作らず、根拠としてのみ**使われます。

**リードタイムの数値は常時監視でのみ得られます**。単発の分析には時間の流れがありません。

> 学習期間に**欠陥がすでに進行していると、その欠陥が正常の基準になってしまいます**。自動フィルターでは除外できない部分なので、学習区間は保全履歴と照らし合わせて人が選ぶ必要があります。ただし、学習軸は等級を作らないため、学習が誤っていても**誤警報にはつながりません** — 根拠の表示が誤るだけです。

## スナップショット成績 — 383件、公開データセット4種

CWRU · MFPT · Paderborn · XJTU-SY。幾何形状（転動体数・転動体径・ピッチ径・接触角）が一次資料に
公開されているものだけを選びました。

| | 結果 |
| :--- | :--- |
| **正常の誤検知** | **3/100 (3%)** |
| **欠陥の検出** | **183/283 (65%)** |
| 欠陥全体のうち部位まで的中 | 153/283 (約54%) |
| 検出分のうち部位の的中 | 153/169 (91%) |

検出は等級がオンになったもの（欠陥パターン採択）だけを数えます。部位的中の分母169は、検出183件のうち欠陥が1種類のケースです（外輪・内輪がともに損傷した複合欠陥14件は、どちらの部位を挙げても的中になるため除外）。このうち4件は転動体候補のため部位不明として出力されます。

**「検出分のうち91%」を単独で引用してはいけません** — 判定が保守的なほど良くなる条件付きの値です。
利用者に実際に残るのは、**欠陥の2件に1件強で部位まで当てる程度**です。

部位別では、**外輪が最もはっきり立ち、内輪は中程度、転動体は部位を示しません**。

> **スナップショットと時間軸とで答えが異なる項目があります**。転動体はスナップショット1枚では事実上捉えられませんが、
> 全寿命試験では**残り72%（約25日）の時点で捉えられました**（NASA IMS Set 1 B4）。
> 問うことが違うからです — 「この1枚で転動体と**名付けられるか**」は幾何形状が重なるため不可能ですが、
> 「このベアリングが**悪化しているか**」は可能です。部位は言えなくても、異常は立ちます。

### 軸を組み合わせるとどうなるか

同じ383件を軸ごとに分けて測ると、次のようになります。

| 軸 | 単独での誤検知 | 単独での検出 |
| :--- | :--- | :--- |
| **欠陥パターン** | **3/100 (3%)** | 183/283 (65%) |
| **ベースライン** | **0/100 (0%)** | 79/283 (28%) |
| 帯域 | 13/100 (13%) | 117/283 (41%) |
| **ISOゾーン** | **69/100 (69%)** | 104/283 (37%) |
| **4軸のうち1つでもオンになれば警報** | **69/100 (69%)** | 209/283 (74%) |
| **現行 — パターンがゲート、ISOが高さ** | **3/100 (3%)** | **183/283 (65%)** |

4軸の最大値を等級として使うと、軸が増えるほど等級は上がる一方なので、ISO軸の単独誤検知69%がそのまま画面上の等級になります。

そこで、**欠陥パターンをゲートに、ISOを高さに**使います。誤検知は69% → 3%に下がり、検出は74% → 65%と9%p減ります。等級は欠陥パターンがオンにしたときだけ上がるため、検出は欠陥パターン単独と同じです。

おまけが1つあります — **マシンクラスの設定を誤っても、誤検知はほとんど変わりません**（Class I・II・IIIすべて3\~4%）。ISOが警報をオンにしないからです。

> **この69%は実機設備の誤検知率ではありません — マシンクラスの設定の問題でもありません**。
> 検証プールはすべて**加速寿命試験台**です。健全な試験台は高荷重で回るため振動がもともと高く、
> 欠陥初期のベアリングは広帯域振動が低くなります。そのためこのプールでは正常と欠陥のISO値がほぼ同じか、
> むしろ正常のほうが高く、ISO値では損傷の有無を区別できません。クラスを緩めても解決しません。
>
> ISO 10816/20816は**正常運転中の実機設備**のための規格であり、加速寿命試験台はその対象ではありません。
> したがって上の表が測っているのは、「**規格の対象ではない装置にISO判定を適用するとどうなるか**」です。

### この設計の代償

| 失ったもの | 大きさ |
| :--- | :--- |
| 検出 9%p (74% → 65%) | 4軸で捉えていたものの一部を見逃します |
| **ベアリング以外の故障の通知** | アンバランス・ミスアライメント・ゆるみでは等級が上がりません |
| **ベースライン軸の通知** | 単独誤検知0%・検出28%と最もクリーンな軸ですが、通知からは外しました |

3つ目は時間軸のためです — ベースラインは速い軸（判定周期）、等級は遅い軸（抽出周期）なので、同じイベントの流れに混ぜるとイベント時刻の意味があいまいになります。**値は根拠表にそのまま残り、通知だけが送られません**。

## 時間軸での成績 — 全寿命試験

NASA IMSの全寿命試験を**実際の監視周期（10分）で**再生し、通知をオフにして判定だけを回した結果です。
最後まで健全だったベアリングが同じ試験台で一緒に回っていたため、誤警報の分母が正しく得られます。

### 欠陥ベアリング — 確定時点

| ベアリング | 部位 | 初回警報（2回連続で確定） | 試験期間 |
| :--- | :--- | :--- | :--- |
| Set 2 B1 | 外輪 | **残り46% = 約3.1日** | 6.8日 |
| Set 1 B4 | 転動体 | **残り72% = 約25日**（部位は特定できず） | 34.5日 |
| Set 1 B3 | **内輪** | **未検出**（末期の単発2回のみ） | 34.5日 |

**2/3を検出**。3つの欠陥はいずれも「**最初の単発 → 長い空白 → 連続区間**」という形でした。単発まで受け入れれば3/3になりますが、そのとき得られる「より早い」警報は最初の単発なので、現場で確認できるものがありません。内輪は試験末期に単発が2回あっただけなので、予防保全には使えません。

### 健全ベアリングの誤警報 — 確定ルール別

健全な7測定点・158日間の実測です。

| 確定ルール | 測定点・月あたりの誤警報 | 欠陥検出 |
| :--- | ---: | ---: |
| 単発でも確定 | **14.6件** | 3/3（すべて単発） |
| **2回連続（現行）** | **5.3件** | **2/3** |
| 3回連続 | 3.0件 | 2/3 |

分母は**測定点**です — 1つのベアリングにチャンネルが2つあればアラームも2つから別々に出るため、運用者が実際に受け取る量は測定点が基準になります。

試験セットごとのばらつきが大きいです。隣のベアリングが破損しつつある最悪の条件（Set 2）で誤警報が集中し、そうでないセット（Set 1）は2回連続の基準で**測定点・月あたり1.1件**でした。通常の環境はSet 1に近いです。

**確定に至らなかった単発も捨てません**。`観察` イベントとして履歴に残ります — 通知が送られないだけです。

> **加速寿命試験の%を実機設備の時間に置き換えないでください**。高荷重の加速試験は、発生段階よりも
> 進展段階をはるかに大きく圧縮します。**実機設備でのリードタイム・誤警報の検証根拠はまだありません**。

## できないこと — 名指しで挙げます

| | 理由 |
| :--- | :--- |
| **内輪の早期検出** | 34.5日の試験でも未検出。変調によってエネルギーが `BPFI ± k·1×` に広がり、支配的なピークが立ちません |
| **転動体の部位特定** | 転動体の欠陥周波数グリッドが外輪のグリッドと重なります。検出はされますが、「部位不明」として出力されます |
| **保持器欠陥** | 欠陥周波数では原理的に不可能。破断は分単位で進行し、予兆がありません |
| **アンバランス・ミスアライメント・ゆるみ** | 位相（タコ信号）・軸方向チャンネルがなければ**原理的に**判別できません。振幅が高いという事実だけを表示し、等級は上げません |
| **なぜ損傷したか（故障モード）** | 疲労・潤滑不良・電食・摩耗は判定しません。部位 + 運転履歴から人が絞り込みます |
| **劣化の第1段階** | AE帯域（20\~60 kHz）にはサンプリングが届きません |
| **秒単位の事故** | 等級判定は抽出周期（既定10分）ごとです。瞬間的な破断・異物混入は、保護継電器・インターロックの領域です |
| **大型・低速・可変速設備** | 検証プールに含まれていません（下記参照） |

> **大型設備で復調帯域が適切かどうかは、まだ分かっていません**。
> 等級を決める欠陥パターンの復調帯域は1\~5 kHzに固定されています。この帯域で実際によく現れるのは**加速度計のマウンティング共振**
> （取り付け方法によって数kHz）であり、ベアリングの軌道輪そのものの曲げモードは、設備が大きくなるほど**低くなります**。
> そのため、「大型設備は共振がより高いので見逃す」という説明は物理的に正しくありません。
> 検証プールに大型設備がないため、**どちらの方向に外れるのかは測定されていません**。

## サンプルの限界

- **時間軸の結果は、NASA IMSのベアリングチャンネル14個のケーススタディです**。百分率だけを引用せず、元の表もあわせて見てください
- **加速寿命試験の偏り** — Paderbornでは、人工加工欠陥のほうが実際の加速寿命損傷よりも明らかによく捉えられました。
  同じ方向の偏りがリードタイムにもある可能性があります
- 検証プールには**大型・低速・可変速設備がありません**
- **実機設備で測定されたことはありません**。上の5.3件は試験台の値です — 通知をオンにする前に、対象設備で通知なしに判定だけを回して（並行運転）、ご自身で測定してください
