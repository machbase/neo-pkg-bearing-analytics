# 문제 해결

**한국어** | [English](./troubleshooting.en.md)

## 설비 카드가 하나도 안 보임

- 앱이 "DB에서 TAG 테이블을 찾지 못했습니다"를 표시하면, Neo에 연결됐지만 TAG table이 없는 경우입니다. Neo 연결 상태와 TAG table 존재를 확인합니다.
- table은 있는데 카드가 없다면, **설정 → 데이터 소스**에서 아직 태그를 선택하지 않은 것입니다. 감시할 태그를 선택하고 저장합니다.

## 데이터 소스에 방금 넣은 태그가 안 뜸

- 데이터 소스 목록은 진입 시점 기준입니다. 태그를 새로 넣었다면 설정 화면을 다시 열어 목록을 갱신합니다.
- 상단에 데이터 소스 변동 배너가 떠 있으면, 선택이 오래된 것입니다. 선택을 갱신하고 저장합니다.

## 프리셋(1시간·6시간 등)이 비활성화됨

그 태그의 데이터가 프리셋 길이보다 짧다는 뜻입니다.

- 눌러 보면 "데이터가 부족합니다" 안내가 뜹니다.
- **전체** 프리셋으로 확인하면 그 태그의 데이터 전 구간을 볼 수 있습니다.
- 데이터가 더 쌓이면 프리셋은 자동으로 다시 켜집니다.

## 상세분석이 실시간으로 안 바뀜

정상입니다. 상세분석은 들어온 시점으로 고정되는 **스냅샷**입니다. 최신 상태를 보려면 상세분석에서 나갔다 다시 들어오거나, 태그를 바꿔 다시 캡처합니다.

## 앱을 다시 열었더니 알람이 꺼져 있음

- 알람 상태는 저장됩니다. 다시 열었을 때 꺼져 있다면, 켠 뒤 설정이 저장되기 전에 창을 닫았을 수 있습니다.
- 헤더의 알람 표시를 눌러 다시 켭니다.

## 이벤트가 기록되지 않음

- **알람이 켜져 있는지** 확인합니다. 판정은 알람이 켜진 동안에만 동작합니다.
- **앱이 열려 있어야** 합니다. 알람은 상시 백그라운드가 아니라 앱이 열린 동안의 감시입니다.
- **양호(정상)는 이벤트로 남지 않습니다.** 주의 이상만 기록됩니다.

## 이벤트 파일을 내려받을 때 "안전하지 않은 파일" 경고

브라우저가 CSV·JSON 다운로드에 대해 표시하는 일반적인 경고입니다. 파일 자체의 문제가 아니며, 다운로드를 유지하면 정상적으로 저장됩니다.

## 진단이 부정확하게 느껴짐

- **설비 정보**에 RPM과 베어링 모델을 등록했는지 확인합니다. 이 값이 없으면 결함 주파수 대조가 제한됩니다.
- 임계값이 설비에 맞는지 **판정 기준**에서 확인하고, 필요하면 조정합니다.
- 정상 상태를 학습해 두면 상대 기준 판정이 함께 적용됩니다.

## LLM 소견이 생성되지 않음

- **설정 → LLM 연동**에 프로바이더가 하나 이상 설정됐는지 확인합니다.
- **연결 테스트**로 API Key 또는 Ollama URL이 올바른지 확인합니다.
- 상세분석·리포트의 프로바이더 드롭다운에서 사용할 프로바이더가 선택됐는지 확인합니다.
- LLM 소견은 선택 기능입니다. 연동하지 않아도 규칙 기반 진단과 리포트는 정상 동작합니다.
