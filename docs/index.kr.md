# 진동 데이터 분석 기술 문서

**한국어** | [English](./index.en.md)

neo-pkg-vibe-analytics는 Machbase Neo TAG table에 쌓인 진동 센서 데이터를 SQL·TQL 작성 없이 설비 건전성 진단으로 바꿔 주는 패키지입니다.

브라우저로 앱을 열면 모든 설비가 ISO 10816 심각도 존 기준으로 실시간 등급이 매겨지고, 태그별 파형·스펙트럼 분석, 규칙 기반 결함 진단과 권고 조치, 원클릭 분석 리포트 생성까지 한 화면에서 이어집니다.

모든 분석은 **결정론적**입니다. 등급 판정·진단·리포트에 LLM은 필요하지 않습니다. LLM은 리포트와 이벤트에 서술형 전문가 소견을 덧붙이는 **선택 기능**으로만 연결됩니다.

## 설치

Machbase Neo 좌측 사이드 패널의 패키지 목록에서 `neo-pkg-vibe-analytics`를 선택하고 `Install` 버튼을 누르면 설치됩니다. 설치가 끝날 때까지 잠시 기다립니다.

### 제거

좌측 패널에서 `neo-pkg-vibe-analytics`를 선택하고 **Uninstall**을 누르면 패키지가 제거됩니다. 그동안 쌓인 이벤트·리포트 등 데이터는 보존됩니다.

## 동작 방식

앱을 실행하면 Neo에 연결해 TAG table을 자동으로 찾고 실데이터로 동작합니다. 사용 가능한 TAG table이 없으면 UI를 둘러볼 수 있도록 데모(목데이터) 상태로 폴백합니다.

분석은 전부 패키지 내부(CGI)에서 결정론적으로 계산됩니다. RMS·FFT·포락선·첨도·베어링 결함 주파수 같은 신호처리와 ISO 10816 등급 판정은 외부 호출 없이 브라우저·CGI 안에서 처리됩니다.

## 화면 구성

상단에 세 개의 주 탭과 설정(⚙) 진입점이 있습니다.

| 탭 | 용도 |
| :--- | :--- |
| 모니터링 | 설비 카드 그리드, 심각도 등급, KPI 요약, 이벤트 목록, 알람 토글 |
| 상세분석 | 선택 태그의 스냅샷 — 파형·추이·FFT·포락선·켑스트럼·스펙트로그램, 규칙 기반 진단 |
| 리포트 생성 | 진동 분석 리포트 생성·미리보기·보관함 |
| 설정 | 데이터 소스 · 설비 정보 · 판정 기준 · 알람 설정 · LLM 연동 |

## LLM 프로바이더 (선택)

리포트·이벤트에 서술형 소견을 덧붙일 때만 사용합니다. 네 가지 프로바이더를 지원합니다.

| 프로바이더 | API | 로컬 |
| :--- | :--- | :---: |
| Claude | Anthropic API | 아니오 |
| OpenAI | OpenAI API | 아니오 |
| Gemini | Google Gemini API | 아니오 |
| Ollama | Ollama REST API | 예 |

연결하지 않아도 등급 판정·진단·리포트는 모두 정상 동작합니다.

## 기본 작업 순서

1. Neo에서 패키지를 설치하고 앱을 엽니다.
2. **설정 → 데이터 소스**에서 분석할 TAG table과 태그를 선택합니다.
3. **설정 → 설비 정보**에서 RPM·베어링 모델·ISO Class를 등록합니다. (선택)
4. **설정 → 판정 기준**에서 임계값을 확인하고, 필요하면 정상 상태를 학습시킵니다.
5. **모니터링** 탭에서 설비 상태를 확인하고, 필요 시 알람을 켭니다.
6. 이상 징후가 보이는 카드를 눌러 **상세분석**으로 들어갑니다.
7. **리포트 생성**에서 대상 태그를 골라 분석 리포트를 만듭니다.
